# Услуга «Интернет-магазин на готовом шаблоне InSales»

Рабочая система Emilius Agency: как найти клиента, продать, оценить, сделать и улучшать эту услугу. Версия 1.0 от 06.10.2026.

**Коротко:** 4 пакета — Экспресс 62 000 ₽, Старт 88 000 ₽, Бизнес 137 000 ₽, Селлер+ 170 000 ₽ (общие остатки WB/Ozon + МойСклад). Вход — Этап 0 за 12 000 ₽, засчитывается. Цены считаются из норм времени, а не придумываются. Приоритетный сегмент — бренды на маркетплейсах с сайтом-визиткой.

## Калькулятор

```bash
node scripts/insales/estimate.mjs                                   # цены пакетов
node scripts/insales/estimate.mjs scripts/insales/examples/seller-wb.json   # смета по брифу
node scripts/insales/build-docs.mjs                                 # пересобрать 03-raboty.md, works.csv, packages.md
```

Нормы и пакеты — `scripts/insales/works.mjs`. Логика брифа и коэффициенты — `scripts/insales/estimate.mjs`.
