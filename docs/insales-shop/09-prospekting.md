## Как искать: процедура на 1 компанию (15–20 минут)

1. Найти по одному из источников выше, записать в таблицу.
2. Открыть сайт и/или карточку продавца. Записать: платформа, домен, есть ли корзина, сколько товаров (оценка).
3. Найти **конкретное наблюдение** — повод для письма: кнопка ведёт на WB; домен tilda.ws; нет фильтра по размеру; заказ тортов только через ВК; нет расчёта доставки.
4. Найти канал: почта на сайте, Telegram, VK, форма. Личный контакт владельца > общая почта.
5. Балл 0–5: бренд (1) + 50+ товаров (1) + повторные покупки в нише (1) + видимый признак боли (1) + доступен личный контакт (1).
6. Писать при балле 3+. Черновик сообщения — в таблицу, перед отправкой перепроверить наблюдение.

## Автоматизация (дешёвая модель или скрипт, не ручной труд)

| Шаг | Чем | Выход |
|---|---|---|
| Сбор кандидатов | поисковые запросы по шаблонам выше; выгрузка SellerStats; Карты по рубрикам | список URL |
| Обогащение | скрипт: платформа сайта (tilda.ws, заголовки), есть ли корзина (`/cart`, «В корзину»), ссылки на WB/Ozon на странице | колонки «платформа», «корзина», «ссылки МП» |
| Скоринг | правила из п. 5 | балл |
| Черновик | дешёвая модель по шаблонам из `10-soobshcheniya.md` + наблюдение | черновик сообщения |
| Проверка | человек: открыть сайт, подтвердить наблюдение, отправить | статус «касание 1» |

Сильная модель не нужна для сбора и черновиков — только для разбора ответов и сложных диалогов.

## Объёмы и воронка (гипотеза на месяц)

100 компаний в таблице → 80 с баллом 3+ → 80 первых сообщений → 12–15 ответов (15–18%) → 6–8 диагностик → 2–3 оплаты (этап 0 или пакет).

## Юридические рамки

Пишем компаниям по публичным контактам, указанным для связи, с конкретным поводом, по одному сообщению + 2 follow-up. Не покупаем базы с личными телефонами, не делаем массовых рассылок, не пишем в личку сотрудникам с личных страниц без связи с бизнесом. Отписка — по первой просьбе, отметка в таблице «не писать».
