# Перечень типовых работ и нормативы времени

> Файл собирается из `scripts/insales/works.mjs` командой `node scripts/insales/build-docs.mjs`. Править нормы — там, не здесь.

Норма — чистое время исполнителя по таймеру, часы. Ставки: **NC** Ноукод-сборщик InSales — 2 400 ₽/ч; **DEV** Разработчик InSales (Liquid/JS) — 3 500 ₽/ч; **INT** Интегратор (1С, МойСклад, МП, CRM) — 3 000 ₽/ч; **DES** Дизайнер UX/UI — 2 400 ₽/ч; **SEO** SEO-специалист — 2 400 ₽/ч; **CNT** Контент-менеджер — 1 500 ₽/ч.
Колонка «Пакеты»: Э — Экспресс, С — Старт, Б — Бизнес, С+ — Селлер+. Сложность: 1 — по чек-листу, 2 — нужен опыт, 3 — нужна оценка по ТЗ.
