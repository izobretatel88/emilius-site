# Пакеты и примеры смет

> Собирается `node scripts/insales/build-docs.mjs` из норм. Цены пакетов — сумма норм × ставки − 10% пакетной скидки, округление вверх до 1000 ₽.

| Пакет | Для кого | Часы | Цена | Срок |
|---|---|---|---|---|
| **Экспресс** | до 50 товаров без учётной системы: продавцы из соцсетей, небольшие бренды, тест канала | 28.66 | **62 000 ₽** | 2–3 нед. |
| **Старт** | до 100 товаров, товары в таблице или на МП, без учёта | 40.66 | **88 000 ₽** | 2–3 нед. |
| **Бизнес** | до 1000 товаров с вариантами, импорт с МП или из файла, 2 оплаты, 3 доставки | 63.36 | **137 000 ₽** | 3–4 нед. |
| **Селлер+** | «Бизнес» + общие остатки с WB и Ozon через InSales «Комбо» и связка с МойСклад | 74.78 | **170 000 ₽** | 3–4 нед. |
| Этап 0 · Диагностика и план | отдельно или как вход в любой пакет; засчитывается при старте в течение 30 дней | ~8 | **12 000 ₽** | 3–5 раб. дней |

Коэффициенты к часам (анкета, раздел «Риски»): materials: ready ×1, partial ×1.15, none ×1.3; dirtyData: clean ×1, some ×1.2, messy ×1.4; urgent: no ×1, yes ×1.25; deciders: one ×1, many ×1.1.

## Примеры смет по брифу

### Пример: зоомагазин с 2 точками, 2000 товаров в 1С, SEO — основной канал

`node scripts/insales/estimate.mjs scripts/insales/examples/offline-1c.json` → **246 800 ₽**, 110.93 ч (NC 66.64, DES 4.03, INT 13.23, SEO 27.03), ~5 нед. Коэффициенты: общий ×1.15, каталог ×1.2.

### Пример: селлер WB/Ozon, 400 товаров с размерами, МойСклад, общие остатки

`node scripts/insales/estimate.mjs scripts/insales/examples/seller-wb.json` → **185 100 ₽**, 76.86 ч (NC 54.56, DES 5.5, INT 12.8, DEV 2.5, SEO 1.5), ~4 нед. Коэффициенты: общий ×1, каталог ×1.2.

### Пример: бренд из Instagram/VK, 40 товаров, фото есть, описаний нет

`node scripts/insales/estimate.mjs scripts/insales/examples/social-small.json` → **83 800 ₽**, 41.05 ч (NC 29.55, CNT 11.5), ~3 нед. Коэффициенты: общий ×1.15, каталог ×1.
