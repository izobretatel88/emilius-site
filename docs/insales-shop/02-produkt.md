# 02 · Продукт: архитектура услуги

## Формула

**Интернет-магазин на готовом шаблоне InSales, доведённый до работающего заказа: товары, оплата, доставка, чеки, аналитика — проверено тестовыми заказами с телефона.**

Для селлера — второй канал рядом с маркетплейсом с общими остатками. Площадки продолжают работать.

Мы не обещаем выручку и трафик. Обещаем: магазин принимает и проводит заказ, видно, откуда пришёл покупатель и сколько он заплатил, сотрудник умеет работать с магазином.

## Лестница продукта

```
Этап 0 · Диагностика (12 000 ₽, засчитывается)
   ↓
Экспресс 62 000 ₽ ─ Старт 88 000 ₽ ─ Бизнес 137 000 ₽ ─ Селлер+ 170 000 ₽
   ↓                       + модули (опции из конструктора)
Поддержка и развитие (часы, пакеты 10/20 ч в месяц)
   ↓
Маркетинг: Директ, SEO, рассылки (направление «Маркетинг» на колесе)
```

Колесо агентства: этап 0 — касдев, сборка — дизайн и разработка, после запуска — маркетинг и снова касдев по данным первых заказов.

Кросс-сейлы внутри агентства: дизайн-упаковка бренда (команда «Лотус»), Tilda-лендинг для промо, кастомная разработка на InSales (3 500 ₽/ч) — когда клиент перерос шаблон.

## Границы продукта (кому отказываем)

- Нет товара и спроса — продаём только этап 0 или отказываем.
- Нужен уникальный дизайн и нестандартная логика по всему сайту — это кастомная разработка, не шаблон.
- Сложный B2B с индивидуальными ценами на каждого клиента — отдельная оценка.
- Клиент хочет, чтобы аккаунт, домен или Метрика были на нас — нет.
