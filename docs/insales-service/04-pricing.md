# 04. Нормативы и расчёт стоимости

Цена считается алгоритмом: **бриф → работы → часы → деньги**. Менеджер не придумывает цену, он заполняет бриф. Код — `calc/calc.mjs`, нормы — `calc/works.mjs`, таблица работ — `03-works.csv`, примеры — `04b-estimates.md`.

## Формула

```
Часы       = Σ (норма работы × количество единиц)
База       = Σ (часы роли × ставка роли)
+ правки   = База × 10%                       (два круга правок и согласований)
+ риск     = Σ (работы уровня 3) × 25%        (1С, парсинг, сложная механика)
+ срочность = База × 0 / 15% / 30%            (обычно / в 1,5 раза быстрее / в 2 раза)
+ согласующие = База × 10%                    (больше одного человека утверждает)
− скидка   = 5% от 40 ч · 10% от 80 ч · 15% от 120 ч · 20% от 160 ч (пакеты часов агентства)
Цена       = округление вверх до 1 000 ₽
```

## Ставки (прайс агентства, 27.06.2026)

| Роль | ₽/ч | Где нужна |
|---|---:|---|
| Ноукод-сборщик InSales | 2 400 | тема, каталог, оплата, доставка, аналитика, обучение |
| Разработчик InSales (Liquid) | 3 500 | правки кода темы, новые блоки, 1С, e-commerce, парсинг |
| Дизайнер UX/UI | 2 400 | баннеры, макеты нестандартных блоков |
| SEO-специалист | 2 400 | ядро, тексты категорий |
| Интегратор CRM | 3 000 | amoCRM, Битрикс24, RetailCRM |

Менеджер и тестировщик входят в командную ставку, их время не считается.

Нормы — **чистые часы** исполнителя по таймеру Weeek. Разговоры об оценке, изучение ТЗ и внутренняя коммуникация не считаются — это правило агентства.

## Единицы норм

| Единица | Пример |
|---|---|
| проект | «Подключение домена и SSL» — 0,5 ч один раз |
| 100 товаров | «Чистка данных» — 0,5 ч на 100 при «частично готовой» таблице |
| штука | «Служба доставки» — 1,5 ч на каждую |

## Сложность и коэффициенты

**Уровень работы** (в `03-works.csv`):
1. Рутина по чек-листу — может делать джун после обучения.
2. Нужен опыт с InSales — мидл.
3. Неопределённость (1С, парсинг, механика) — мидл+, к часам +25% запаса.

**Качество данных клиента** — главный источник перерасхода, фиксируется в брифе:

| Значение | Признак | Чистка на 100 товаров |
|---|---|---:|
| ready | таблица по нашему шаблону, свойства в колонках | 0 ч |
| partial | своя таблица, названия разнобой, свойства в тексте | 0,5 ч |
| messy | фото в папках, цены в PDF, дубли | 1 ч |

Если товары с маркетплейса — чистка × 0,5 (карточки уже структурированы).

## Правила фиксированной цены

Формат «ФИКС» агентства: перерасход до 30% — наш риск; свыше 30% — доплата по согласованию; сэкономили больше 30% — возвращаем. Для пакетов запуска добавляем:

1. Объём фиксируется по брифу (количество товаров, категорий, способов оплаты и доставки, интеграций). Изменение брифа = пересчёт калькулятором, а не торг.
2. Работы уровня 3 (1С, парсинг, M4) при неясном аудите переводятся в формат «ЧАСЫ» с потолком.
3. Ожидание банка, кассы, материалов клиента не входит в срок. Срок считается с момента получения материалов по чек-листу.

## Оплата

ПРЕД50: 50% до старта, 50% после тестового заказа и передачи. Этап 0 — 100% предоплата, засчитывается в первый платёж. Документы по ЭДО (Точка).

## Срок

```
Рабочие дни = Часы / 4 продуктивных часа / 1,5 исполнителя
Срок (нед.) = дни / 5 + 1…2 недели на ожидание банка, кассы и материалов
```

## Проверка цены перед отправкой клиенту

- [ ] Бриф заполнен полностью, «не знаю» заменено разумным допущением и записано в смету.
- [ ] Тариф InSales и платные приложения проверены на insales.ru в день сметы.
- [ ] Все работы уровня 3 имеют аудит или формат «ЧАСЫ».
- [ ] В смете отдельно: работа Emilius / подписка и приложения / эквайринг, касса, доставка / реклама.
- [ ] Цена не ниже «от» пакета. Скидка — только снятием работ, не снижением ставки.

## Как обновлять нормы

После каждого проекта: факт по таймеру Weeek против нормы по каждой работе (лист «факт/норма»). Если отклонение больше 25% на трёх проектах подряд — правим норму в `works.mjs`, пересобираем `03-works.csv` и `04b-estimates.md`, пишем строку в журнал `12-improvement.md`.
