## Как пользоваться

```bash
# смета по брифу
node docs/insales-service/calc/calc.mjs docs/insales-service/calc/examples/seller.json

# после правки норм в calc/works.mjs — пересобрать таблицу работ и примеры
node docs/insales-service/calc/calc.mjs --csv > docs/insales-service/03-works.csv
```

## Решения, которые нужны от владельца

1. Утвердить цены пакетов и Этапа 0 (или поправить ставку/нормы).
2. Вести ли «Экспресс» — дешёвый вход, но клиент сам заводит товары.
3. Скидки на абонемент (−5% за 10 ч, −10% за 20 ч).
4. Агентское вознаграждение партнёрам 10%.
5. Адрес лендинга `/insales/` и запуск теста Директа на 30 000 ₽.
