# 08. Поиск клиентов: каналы, проспектинг, квалификация

Оценки стоимости контакта и вероятности сделки — **стартовые гипотезы** (данных по каналам у Emilius нет). Записывать факт в таблицу лидов и пересматривать через 8 недель.

## 2. Проспектинг: кого искать

| **A2** | Бренд/производство только на МП | WB/Ozon, страница бренда | Категория с повторными покупками (бельё, косметика, зоотовары, детское, чай/кофе, БАДы) → фильтр «бренд» → бренды с 50+ товарами и рейтингом 4.7+ → поиск бренда в Яндексе | Поиск в Яндексе `"<бренд>" официальный сайт`; сайты на `*.tilda.ws`, `taplink`, `orgs.biz`, страницы с кнопками на WB | Нет сайта / визитка; 2+ площадки; есть Telegram/VK бренда; новости о запуске |

## 3. Скоринг холодного лида (для таблицы «Emilius · InSales · лиды»)

Сохраняем правило v2 от 06.10 и делаем его полным:

| Признак | Балл |
|---|---|
| Свой бренд или производство | +2 |
| Продажи на 2+ площадках | +1 |
| Категория с повторными покупками | +1 |
| Сайта нет, визитка на поддомене или кнопки «купить на WB» | +1 |
| Есть своя аудитория (VK/Telegram 3 000+, брендовые запросы) | +1 |
| 100+ товаров или варианты | +1 |
| Перепродажа без бренда | −2 |
| Контакт ЛПР не найден | −1 (если нашли позже — снять) |
| Поддомен tilda.ws без бренда и производства | −2 (не снимается, только если есть своё производство и продажи на WB/Ozon) |
| Уже нормальный магазин на InSales/Bitrix с остатками | −3 |

**4–5** — писать в первую очередь, персонально; **2–3** — писать после проверки сайта вручную; **0–1** — не писать.

## 4. Квалификация входящего лида (после 8 вопросов брифа)

| Критерий | 0 | 1 | 2 |
|---|---|---|---|
| Продажи сейчас | нет | < 50 заказов/мес | 50+ заказов/мес |
| Источник покупателей для сайта | нет | есть, но не измерен | подписчики/база/брендовый спрос |
| Ответственный за заказы | нет | владелец сам | сотрудник |
| Бюджет | < 50 тыс. | 50–100 тыс. | 100 тыс.+ |
| Срок/триггер | «когда-нибудь» | в течение полугода | конкретное событие и дата |

**7–10** → сразу этап 0. **4–6** → этап 0 с акцентом на экономику или «Пилот». **0–3** → вежливо отказать: полезный материал + вернуться через 3 месяца.
