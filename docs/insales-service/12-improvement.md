### Измерять (с первого лида)

Воронка — одна строка на лид в таблице лидов:

```
касание → ответ → балл ≥ 5 → созвон → Этап 0 / смета → предоплата → запуск → первый заказ клиента → абонемент через 30 дней
```

| Метрика | Порог для решения |
|---|---|
| Факт часов / норма по каждой работе | отклонение > 25% на 3 проектах → правим норму |
| Перерасход проекта | > 15% в среднем → поднять коэффициент правок или риска |
| Ответы на исходящие по сегментам | < 5% после 40 касаний → менять повод или сегмент |
| Заявка → оплата по каналам | через 8 недель — пересобрать рейтинг каналов |
| Этап 0 → проект | < 40% → пересмотреть, кому предлагаем Этап 0 |
| Абонемент через 30 дней | < 30% → усилить отчёт «30 дней» |

### Проверить гипотезы (из исследования, по приоритету)

1. «Добавить канал» откликается лучше, чем «магазин под ключ» — A/B первого экрана.
2. Смета владения на 12 месяцев повышает переход к оплате.
3. Платный Этап 0 отсеивает незрелых, а не отпугивает зрелых.
4. Селлеру важнее общие остатки, чем дизайн — интервью + два оффера.
5. Карточка партнёра InSales даёт лучшие заявки, чем Директ.
