## Проспектинг: кого и как искать

### A2 / A1 — бренды на WB и Ozon (основной)
**Где:** поиск по категориям WB/Ozon в нишах с повторными покупками (косметика, уход, бельё, домашний текстиль, товары для животных, детское, чай/кофе/полезные продукты, хобби, спорт-питание); MPStats (бесплатно: поиск по продавцу и оценка продаж); страница продавца на WB/Ozon → ИНН и юрлицо; поиск бренда в Яндексе.
**Признаки (балл, правило v2 таблицы лидов):**
- +2 свой бренд или производство (название бренда = название продавца, «фабрика», «производитель», СТМ);
- +1 продаёт на 2+ площадках;
- +1 повторная категория;
- +1 нет корзины (нет сайта, визитка, Taplink, tilda.ws);
- +1 100+ SKU;
- −2 сайт на поддомене tilda.ws (по v2 не снимается даже при своём производстве и продажах на WB/Ozon).
  **Предложение к v3:** для A2 поддомен tilda.ws — это и есть признак потребности (бренд без своего магазина), а не минус. В прогоне 06.10 15+ лидов с tilda.ws получили 0 и выпали. Проверить: дать им 0 вместо −2 и посмотреть ответы на 20 сообщений
- −1…−2 бренд или контакт не подтверждены.
Брать в работу с баллом ≥3.
**Повод для сообщения:** новые комиссии в их категории; карточка с высоким рейтингом и отзывами о бренде; есть Instagram/Telegram бренда, но нет сайта; сайт-визитка без корзины.
**Контакт:** сайт/визитка → почта для сотрудничества или Telegram; соцсети бренда (личные сообщения); LinkedIn-аналог — VK владельца; телефон из карточки организации — только для B2B-звонка.

### C — продажи в соцсетях
**Где:** VK-сообщества с разделом «Товары» и 1 000+ подписчиков; Telegram-каналы брендов с «пишите в лс для заказа»; Taplink/«ссылка в описании» без корзины.
**Признаки:** регулярные посты с ценами, комментарии «как заказать?», 30+ товаров, нет сайта.
**Повод:** «вижу, заказы принимаете в личке — сколько времени уходит на оформление?»

### D — магазины на Tilda, которым тесно
**Где:** поиск Яндекса `"tilda" интернет-магазин` + ниша; признаки в коде страницы — `tildacdn`, `t-store`; футер «Made on Tilda»; поддомен `*.tilda.ws`. Определение платформы — расширение Wappalyzer/просмотр кода.
**Признаки:** 100+ товаров в Tilda Store, нет фильтров, есть соцсети и реклама.
**Повод:** «у вас 300 товаров без фильтров по размеру — покупатель листает до конца?»

### B — офлайн-розница и производители
**Где:** 2ГИС и Яндекс Карты по категориям (зоомагазины, косметика, бельё, ткани, хобби, цветы, фермерские продукты) в городах 300 тыс.+; производители — каталоги выставок и «Сделано в России».
**Признаки:** 2+ точки или много отзывов, сайт отсутствует/визитка/каталог без корзины, есть соцсети.
**Повод:** вторая точка, отзывы «а доставка есть?».

### E — устаревшие магазины
**Где:** поиск по нишам, признаки — WordPress/WooCommerce, OpenCart, старый Битрикс в коде, дизайн 2015 года, нет мобильной версии, медленная загрузка.
**Признаки:** есть трафик (видны в поиске по брендовым и товарным запросам), но неудобная корзина.
**Повод:** конкретная проблема: «корзина на телефоне не нажимается», «оплата только переводом».

### Партнёры (отдельная воронка)
Список: бухгалтеры селлеров, фулфилменты, интеграторы МойСклад/1С, фотостудии для МП, менеджеры по выводу на МП, курсы для селлеров. Предложение: 10% с оплаченного проекта или обмен клиентами (их услуга — нашим клиентам). Цель — 5 активных партнёров за 2 месяца.

## Правила исходящих (юридические и этические)

- Только персональные деловые сообщения конкретной компании, с наблюдением о её бизнесе. Никаких массовых рассылок и шаблонов «Уважаемый партнёр».
- Email/SMS-реклама без согласия запрещена ст. 18 38-ФЗ — письмо должно быть деловым предложением конкретному адресату, без рекламных шаблонов; с личной рабочей почты, не через сервис рассылок. Перед масштабированием показать формат юристу.
- Контакты конкретных людей — персональные данные (152-ФЗ): не собираем в базы сверх нужного, удаляем по первой просьбе.
- Отказ = отказ. Больше не пишем, помечаем в таблице.
- Не больше 3 касаний.
