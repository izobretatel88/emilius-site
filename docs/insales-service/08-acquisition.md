### Порядок ручного проспектинга (30 лидов за 2 часа)

1. Выбрать одну нишу на неделю (повторная категория, см. выше).
2. На WB/Ozon открыть топ-100 по категории → выписать бренды, не являющиеся крупными сетями.
3. Для каждого: поиск «{бренд} официальный сайт». Нет сайта / визитка / кнопки на МП → кандидат.
4. Найти контакт: сайт → Telegram/WhatsApp/почта → соцсети → ЛПР в VK/Telegram. **Без контакта не записываем.**
5. Записать в таблицу «Emilius · InSales · лиды» и посчитать балл.
6. Написать черновик первого сообщения с конкретным наблюдением (09-sales.md).

## Скоринг лида v3

Уточнение правила v2 от 06.10: «−2 за поддомен» убираем, поддомен — это признак потребности, а не минус. Минус ставим только за то, что мешает продаже.

| Признак | Баллы |
|---|---|
| Свой бренд или производство подтверждены | +2 |
| Продаёт на 2+ площадках | +1 |
| Повторная категория (расходники, косметика, бельё, корм, еда) | +1 |
| Нет своей корзины (визитка, ссылки на МП, только соцсети) | +1 |
| Каталог 30+ SKU | +1 |
| Найден рабочий контакт ЛПР или бренда | +1 |
| Контакт не найден | −2 |
| Перепродажа чужих брендов | −1 |
| Нетиповой товар (под заказ, конструктор) | −1 |
| Уже есть магазин на InSales/Bitrix с интеграциями | −3 |

**Пороги:** 5+ — писать сегодня; 3–4 — писать после проверки сайта вручную; ≤2 — не писать.

**Перескоринг прогона 06.10 по v3** (из таблицы, без новой проверки): YERRNA и EDELSON — +5 без учёта контакта (+2 бренд/производство, +1 площадки, +1 нет корзины, +1 повторная категория), InterStellar — +4 (категория не повторная, SKU не видно). Итог зависит от контакта: найден — +1, не найден — −2. **Первым шагом найти контакты этих трёх.** Tilda-магазины с корзиной без подтверждённого бренда остаются на 0–2.
