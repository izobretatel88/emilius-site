# 05. Квалификация и бриф

Три уровня вопросов, от короткого к длинному. Каждый следующий задаём, только если прошли предыдущий.

```
5 вопросов квалификации (переписка, 5 минут)  →  балл 0–10  →  созвон-диагностика 30 мин  →  бриф (15 минут клиента)  →  калькулятор  →  смета
```

## 1. Квалификация: 5 вопросов

Задаём в переписке по одному-два, не анкетой.

| # | Вопрос | Ответ → баллы |
|---|---|---|
| Q1 | Где сейчас продаёте и примерно сколько заказов в месяц? | нигде — 0 · соцсети/директ — 1 · МП или офлайн до 100 заказов — 2 · больше 100 — 3 |
| Q2 | Товар ваш (бренд, производство) или перепродажа? | перепродажа без бренда — 0 · свой бренд/производство — 2 |
| Q3 | Откуда придут первые покупатели на сайт? | «не знаю» — 0 · база/подписчики/офлайн-точка/брендовый поиск — 2 |
| Q4 | Где сейчас лежат товары: таблица, маркетплейс, 1С/МойСклад? | ничего нет — 0 · есть где-то — 1 |
| Q5 | Когда хотите запуститься и кто решает? | «когда-нибудь» — 0 · срок и ЛПР в переписке — 2 |

| Сумма | Что делаем |
|---|---|
| 8–10 | Горячий. Созвон в течение 24 ч, после — бриф и смета |
| 5–7 | Тёплый. Созвон-диагностика или Этап 0 за 9 900 ₽ |
| 3–4 | Рано. Экспресс или честное «вам пока хватит KIT/Tilda», статья в подарок, напоминание через 2 месяца |
| 0–2 | Не наш клиент. Вежливо закрыть |

**Стоп-факторы** (не продаём шаблон независимо от балла): нетиповые B2B-цены по договорам, маркетплейс-площадка на сайте (многопродавец), бюджет меньше 72 000 ₽ и нет времени заводить товары самим, просьба «перенаправить покупателей с WB» в обход правил.

## 2. Созвон-диагностика (30 минут)

Цель — понять ситуацию и решить, какой следующий шаг. Не презентация.

1. «Расскажите, что случилось, что вы решили сделать магазин сейчас?» — ищем событие-триггер.
2. «Что будет, если ничего не делать ещё полгода?» — проверяем, есть ли боль.
3. «Кто будет принимать заказы с сайта?»
4. «Как будете приводить людей первые три месяца?»
5. «Какие варианты уже смотрели: Tilda, KIT, фрилансер, сами?»
6. «Какую сумму закладывали на запуск и на первый год?»
7. Показать 1–2 похожих магазина из кейсов и тестовый заказ на телефоне.
8. Договориться: бриф до даты X, смета через 1 рабочий день после брифа.

## 3. Бриф клиента

Форма для клиента (Google Форма или Telegram-бот). Справа — поле калькулятора в `calc/calc.mjs`. Пустой ответ = значение по умолчанию.

### Бизнес

| Вопрос | Поле | По умолчанию |
|---|---|---|
| Название, сайт/страница, ниша | `client` | — |
| Где продаёте сейчас (WB, Ozon, ЯМ, Мегамаркет, соцсети, офлайн) | `marketplaces[]` | [] |
| Отгружаете со своего склада (FBS) или со склада площадки (FBO)? | `fbs` | false |
| Есть ли сайт сейчас? Адрес, платформа, сколько страниц в поиске | `migration.urls` | — |
| Сколько человек согласует работу с вашей стороны? | `approvers` | 1 |
| Желаемая дата запуска | `urgency` (0/1/2 по сравнению со сроком калькулятора) | 0 |

### Каталог

| Вопрос | Поле | По умолчанию |
|---|---|---|
| Сколько товаров (с учётом размеров/цветов как одного товара)? | `sku` | 50 |
| Сколько категорий в меню? | `categories` | 10 |
| По каким характеристикам покупатель выбирает (размер, цвет, материал…)? Сколько их? | `properties` | 6 |
| Есть ли размеры/цвета у одного товара? | `variants` | true |
| Где лежат товары: таблица / маркетплейс / 1С / МойСклад / старый сайт / нигде | `source` | table |
| Насколько готова таблица: по нашему шаблону / своя / фото и цены вразброс | `dataQuality` | partial |
| Сколько товаров без описаний? | `descriptions` | 0 |
| Сколько фото нужно привести к одному виду? | `photosToProcess` | 0 |

### Учёт и интеграции

| Вопрос | Поле |
|---|---|
| Учёт: нет / МойСклад / 1С (какая конфигурация и кто её ведёт) | `accounting` |
| Заказы с сайта должны попадать в 1С? | `ordersTo1c` |
| CRM: нет / amoCRM / Битрикс24 / RetailCRM | `crm` |
| Телефония, колл-трекинг | `telephony` |

### Оплата и доставка

| Вопрос | Поле |
|---|---|
| Сколько способов онлайн-оплаты (банков)? Есть ли договор эквайринга? | `payments` |
| Нужны СБП, оплата частями? | `sbp` |
| Оплата при получении, счёт для юрлиц? | `cod`, `b2bInvoice` |
| Точки самовывоза — сколько? | `pickupPoints` |
| Своя курьерская доставка по городу? | `courier` |
| Сколько служб доставки (СДЭК, Почта, Boxberry, Яндекс…)? | `carriers` |

### Оформление

| Вопрос | Поле |
|---|---|
| Хотите минимальный вариант: тема как есть, товары заводите сами? | `package: "express"` |
| Сколько баннеров нужно нарисовать? | `banners` |
| Какие страницы кроме стандартных (о бренде, опт, гарантия)? | `extraPages` |
| Что в выбранной теме хочется поменять (список)? | `smallTweaks` (до 1 ч каждая) |
| Нужны блоки, которых нет в теме? | `newBlocks`, `newBlocksDesign` |
| Нужна особая механика (конструктор, калькулятор)? | `complexMechanics` — только после ТЗ |
| Отдельные лендинги коллекций | `landings` |

### Маркетинг и аналитика

| Вопрос | Поле |
|---|---|
| Планируете рекламу в Директе/Товарах? (e-commerce, фид) | `ecommerce`, `feed` |
| Реклама в VK? | `vkPixel` |
| Поиск — основной канал? Нужны ядро и тексты категорий? | `seo: "core"`, `seoTexts` |
| Есть офлайн-точки на Картах/2ГИС? | `localSeo` |
| Бонусы и промокоды / рассылки / отзывы / сертификаты | `bonuses`, `mailing`, `reviews`, `certificates` |
| Почта на домене | `domainMail` |

### Перенос (если есть старый сайт)

| Вопрос | Поле |
|---|---|
| Сколько страниц в поиске (Вебмастер) | `migration.urls` |
| Есть выгрузка товаров из админки? | `migration.export` (нет выгрузки → true, нужен парсинг) |
| Переносим покупателей и заказы? | `migration.customers` |
| Сколько статей/страниц | `migration.articles` |

## 4. Из брифа в смету

1. Ответы → JSON по полям выше (позже — автоматически из формы).
2. `node docs/insales-service/calc/calc.mjs brief.json` → таблица работ, часы, цена, срок, смета года.
3. Проверка по чек-листу из `04-pricing.md`.
4. Смета клиенту: пакет, состав, цена, срок, что делает клиент, смета года, условия оплаты. Шаблон — `07-service-card.md`, раздел «Коммерческое предложение».
