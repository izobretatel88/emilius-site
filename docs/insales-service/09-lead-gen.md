## Проспектинг: кого искать и по каким признакам

Балл кандидата — **правило v2** (как в таблице лидов от 06.10.2026):

| Признак | Балл |
|---|---:|
| Свой бренд или производство (подтверждено) | +2 |
| Продаёт на 2+ площадках | +1 |
| Повторная категория (косметика, бельё, корма, бытовая химия, чай/кофе, детское) | +1 |
| Сайт без корзины / визитка / кнопки «купить на WB» / домен tilda.ws | +1 |
| Контакт ЛПР найден (Telegram, почта, телефон) | +1 |
| Контакт не найден | −2 |
| Перепродажа без бренда | −2 |
| Сложный для шаблона каталог (торты на заказ, конфигуратор) | −1 |

Писать: балл ≥ 3. В работу «сегодня»: балл ≥ 4.

### Рабочий ритм проспектинга

- 2 часа в неделю → 20–25 проверенных кандидатов → 10–15 первых касаний.
- Таблица: продолжать «Emilius · InSales · лиды» (Drive), колонки уже правильные. Добавить колонки: «касание 2», «касание 3», «ответ», «балл квалификации», «следующий шаг».
- Перед отправкой — открыть сайт и проверить наблюдение из повода (правило таблицы).
- Механическую часть (сбор брендов из категории, проверка сайта и платформы) отдать дешёвой модели или скрипту; Эмиль/менеджер — проверка и отправка.

### Автоматизация (следующий шаг)

1. Скрипт: список брендов категории WB → поиск сайта → определение платформы (заголовки, `tilda.ws`, `myinsales.ru`, отсутствие `/cart`) → балл v2 → строка в таблицу. Ручная проверка остаётся обязательной.
2. Еженедельный прогон по одной нише (бельё → косметика → зоо → детское → дом) — в той же таблице, с датой прогона.
