# 04. Бриф клиента

Две части: **квалификация** (8 вопросов, 5 минут, в первом разговоре или в форме на сайте) и **бриф для сметы** (25 вопросов, заполняем вместе на этапе 0). В скобках — поле калькулятора.

## Часть 1. Квалификация (до этапа 0)

| # | Вопрос | Зачем | Красный флаг |
|---|---|---|---|
| 1 | Что продаёте и где сейчас продаёте? | Сегмент A–E | «Пока нигде, только идея» → сегмент E |
| 2 | Сколько примерно товаров вместе с размерами/цветами? | Пакет | — |
| 3 | Сколько заказов в месяц сейчас по всем каналам? | Есть ли спрос | 0 заказов |
| 4 | Откуда придут покупатели на сайт? (подписчики, база, бренд ищут в Яндексе, реклама) | Нет источника = пустой сайт | «Сайт сам приведёт» |
| 5 | В чём ведёте товары и остатки? (таблица, МойСклад, 1С, кабинет МП) | Интеграции | Самописная 1С без программиста |
| 6 | Кто будет обрабатывать заказы с сайта? | Операционка | «Никто, сам как-нибудь» при 50+ заказах |
| 7 | Когда нужен запуск и почему к этой дате? | Срочность, триггер | — |
| 8 | Какой бюджет заложили на запуск и на первые 3 месяца работы магазина? | Платёжеспособность | Меньше 50 тыс. на всё |

**Решение после квалификации** — см. скоринг в `08-lead-generation.md`, раздел «Квалификация входящего лида».

## Часть 2. Бриф для сметы (этап 0)

### Бизнес
1. Сегмент: селлер (A) / соцсети (B) / офлайн, производство (C) / старый сайт (D) / новый (E). (`segment`)
2. Средний чек и маржа после всех расходов на МП. (для расчёта экономики S0.03)
3. Покупают повторно? Как часто? (`repeat`, `loyalty`)
4. Есть своя аудитория вне МП: подписчики, база с согласиями, брендовые запросы? (`hasAudience`)
5. Кто принимает решение по проекту? Сколько человек согласует? (`deciders`)
6. Это первый сайт? (`firstSite`)

### Каталог
7. Сколько товаров (SKU)? (`sku`)
8. Сколько категорий, сколько уровней? (`categories`)
9. Есть варианты: размер, цвет, объём? (`variants`)
10. Какие характеристики нужны для фильтров? Сколько? (`params`)
11. Откуда берём товары: таблица / кабинет WB/Ozon / фид старого сайта / заводим вручную / из учёта? (`source`: `excel` / `mp` / `yml` / `none`; при 1С и МойСклад — автоматически)
12. Данные чистые? (одинаковые артикулы на всех площадках, единое написание) (`dataQuality`: `clean` / `dirty`)
13. Есть фото на белом фоне и описания? (`content`: `ready` / `partial` / `none`; `photoProcessing`)
14. Продаёте оптом? (`b2b`)

### Внешний вид
15. Шаблон: из бесплатных / платный / хотите свой дизайн? (`design`: `template` / `custom`)
16. Нужны блоки или страницы, которых нет в шаблоне? Сколько? (`customBlocks`, `customPages`, `cssFixes`)
17. Готовы баннеры? Сколько нужно сделать? (`banners`)
18. Сколько информационных страниц и статей переносим? (`infoPages`, `blogPosts`)

### Деньги и доставка
19. Способы оплаты: карта/СБП, при получении, счёт юрлицам, рассрочка? (`payments`: `card`, `sbp`, `cod`, `invoice`, `second`; `installments`)
20. Доставка: самовывоз (сколько точек), свой курьер, СДЭК, Почта, Boxberry, Яндекс? Бесплатная от суммы? (`delivery`, `pickupPoints`, `freeShipping`)

### Связи
21. Маркетплейсы: какие связать? Нужны общие цены по правилам? Заказы с площадок в одном окне? (`marketplaces`, `mpPrices`, `mpOrders`, `yandexFeed`)
22. Учёт: нет / МойСклад / 1С (какая конфигурация, есть ли 1С-программист)? Заказы выгружать в учёт? (`accounting`, `ordersTo1c`, `clientsTo1c`)
23. CRM, телефония, рассылки? (`crm`: `amo` / `b24` / `retail`; `phone`; `emailMarketing`)

### Запуск
24. Домен: есть / купить / занят старым сайтом? Почта на домене? Старый сайт с трафиком — сколько страниц? (`domain`: `have` / `buy` / `move`; `mail`; `migration`, `urls`, `moveCustomers`, `moveOrders`)
25. Аналитика и реклама: планируете Директ/VK? Нужен отчёт для собственника? SEO — один из основных каналов? (`analytics`: `basic` / `ecom`; `ads`; `dashboard`; `seo`: `base` / `extended`). Срок жёсткий? (`urgent`)

## Список материалов от клиента (отправляем после предоплаты)

- [ ] Доступ владельца к InSales (или почта и телефон, чтобы завести магазин на клиента)
- [ ] Логотип в векторе (SVG/PDF), цвета, шрифты, если есть брендбук
- [ ] Таблица товаров по нашему образцу или API-ключ кабинета WB/Ozon (только чтение и остатки)
- [ ] Фото товаров, тексты для главной и «О нас»
- [ ] Реквизиты ИП/ООО, условия возврата, контакты, часы работы
- [ ] Договор с платёжным сервисом (или данные для заявки), онлайн-касса/ОФД
- [ ] Договоры со службами доставки, адреса самовывоза
- [ ] Доступ к DNS домена
- [ ] Доступ к Яндекс ID компании (Метрика, Вебмастер)
- [ ] Для 1С: контакт 1С-программиста, конфигурация и версия
- [ ] Контакт сотрудника, который будет обрабатывать заказы

## Шаблон ответа после брифа

> Спасибо, посчитали. Ваш проект — пакет «{пакет}» + {опции}. Стоимость {цена} ₽, не больше {верх коридора} ₽, если не меняем объём. Срок {N} недель с момента, когда у нас есть материалы. Отдельно платите InSales: тариф «{тариф}» — {сумма} ₽/мес. Смета по работам — в приложении. Следующий шаг — договор и предоплата 50%, после неё в тот же день пришлём список материалов.
