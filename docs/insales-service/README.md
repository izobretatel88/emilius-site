## Как пользоваться

1. **Пришёл лид** → квалификация из 5 вопросов (`04-estimation.md`) → диагностика.
2. **На диагностике** → бриф → `calculator.html` → «Скопировать смету» → КП.
3. **Проект** → этапы `05-process.md`, задачи в Weeek с id из каталога.
4. **После проекта** → факт часов в журнал калибровки (`11-improvement.md`).

```bash
node scripts/insales-calc.mjs              # 5 типовых сценариев (проверка норм)
node scripts/insales-calc.mjs -v           # с разбивкой по работам
node scripts/insales-calc.mjs brief.json   # смета по брифу (поля — DEFAULT_BRIEF в calc/estimate.js)
node scripts/insales-calc.mjs --html       # пересобрать calculator.html после правки CSV
python3 scripts/import-vnimnomic.py "<Задачи и подсчеты>.xlsx"   # обновить data/orders-hours.csv из новой выгрузки
```

Сырые выгрузки с перепиской клиентов и деньгами в публичный репозиторий не кладём. Соответствие кодов проектам пишется в `data/private/` (в `.gitignore`).

## Главные решения v1

- Сдаём по рабочему заказу с телефона, а не по «сайт готов».
- Три пакета: Старт от 75 тыс. ₽, Магазин от 105 тыс. ₽, Селлер от 115 тыс. ₽. Платформа и сервисы — отдельной строкой.
- Позиционирование для селлеров: «добавить канал», а не «уйти с маркетплейсов».
- Обязательный вопрос о трафике в квалификации: магазин без источника покупателей не продаём молча.
- Все доступы на клиенте.
