# Услуга «Магазин на InSales под ключ» — рабочая система

Продукт Emilius Agency: интернет-магазин с нуля на готовом шаблоне InSales для малого бизнеса и продавцов маркетплейсов. Здесь всё, чтобы находить клиентов, продавать, оценивать, делать и улучшать услугу.

**Версия:** v1 от 07.10.2026. **Статус:** черновик для проверки владельцем. Цены — гипотеза, не сверены с рынком (см. открытые вопросы).

## Как посчитать проект

```bash
# 1. Скопировать пример брифа и заполнить по 04-brief.md
cp docs/insales-service/data/brief-m-seller.json /tmp/brief.json
# 2. Получить смету в Markdown
node scripts/insales-estimate.mjs /tmp/brief.json
```

Нормативы правятся в `data/works.csv` (открывается в Google Таблицах, разделитель `;`), ставки и коэффициенты — в начале калькулятора.
