# Услуга «Интернет-магазин на готовом шаблоне InSales»

Рабочая система Emilius Agency: как находить клиентов, продавать, оценивать, производить и улучшать услугу. Версия 1.0 от 08.10.2026.

**Коротко:** три пакета — Старт 59 000 ₽ (10 дней), Магазин 119 000 ₽ (15–20 дней), Магазин + синхронизация 169 000 ₽ (20–30 дней); Этап 0 «Диагностика» — 15 000 ₽, засчитывается. Сдаём, когда проходят три тестовых заказа. Главный сегмент — бренды и производства на WB/Ozon и офлайн-магазины с учётом.

## Калькулятор

Открыть `calculator.html` в браузере (работает без интернета) или по ссылке: https://claude.ai/artifact/51pBKR7LmiPxfFnWFQBNMN (приватная, делиться через меню «Поделиться»). Отметить ответы брифа — справа цена, пакет, допработы и состав работ. Кнопка «Скопировать бриф» сохраняет ответы в JSON.

Из терминала:

```bash
cd docs/insales-service/tool
node estimate.mjs --calibrate        # эталонные проекты: часы, смета, предложение
node estimate.mjs --preset seller    # смета эталона
node estimate.mjs ../brief.json      # смета по брифу клиента
node build.mjs                       # после правки нормативов/ставок: works.csv, прайс, калькулятор
```

Источник правды — `tool/works.mjs` (работы и нормативы) и `tool/rules.mjs` (ставки, пакеты, коэффициенты, логика брифа). `data/works.csv`, `05-price-list.md` и `calculator.html` собираются из них — руками не править.

## Что сделать первым (из бэклога)

1. Собрать магазин-заготовку на InSales — от неё посчитаны нормативы.
2. Сверить тарифы InSales на insales.ru/signup.
3. Обновить карточку в каталоге партнёров InSales.
4. Начать холодный поиск A2 по таблице лидов (20 лидов в неделю) с сообщениями из `10-outreach.md`.
