# Услуга «Свой интернет-магазин на InSales» — рабочая система

Продукт Emilius Agency: запуск интернет-магазина на готовом шаблоне InSales для малого бизнеса и продавцов маркетплейсов. Здесь всё, чтобы находить клиентов, продавать, оценивать и делать эту услугу одинаково хорошо.

Версия 1.0 · 07.10.2026 · источники: исследование ЦА от 27.09 (Drive), прогон лидов 06.10 (Drive, таблица «Emilius · InSales · лиды»), внутренние документы агентства (ставки, процесс, проекты Endorphine и Happy Animal).

## Коротко

| | |
|---|---|
| Оффер | Свой магазин рядом с маркетплейсами: общие остатки с WB/Ozon или учётом, проверенные оплата и доставка, запуск за 3–6 недель |
| Главный сегмент | Бренды и производители, которые продают на WB/Ozon и не имеют своего магазина |
| Вход | Этап 0 «Диагностика» — 15 000 ₽, засчитывается в проект |
| Пакеты | Пилот 69 000 ₽ · Старт 99 000 ₽ · Маркетплейс + сайт 159 000 ₽ · Магазин с учётом 209 000 ₽ (МойСклад) / от 229 000 ₽ (1С) |
| Цена вне пакета | Калькулятор: бриф → 117 атомарных работ → часы → цена |
| Ставки | 2 400 ₽/ч ноукод и дизайн, 3 500 ₽/ч интеграции, 4 200 ₽/ч продакт |

## Как пользоваться

```bash
# смета для клиента
node docs/insales-service/calculator/calc.mjs docs/insales-service/calculator/briefs/seller.json
# каталог работ таблицей
node docs/insales-service/calculator/calc.mjs --csv > docs/insales-service/works-catalog.csv
```

Готовые сметы-примеры — `calculator/estimates/`. Поменять ставку или скидки — `PRICING` в `calc.mjs`; нормы работ — `catalog.mjs`. После правки — перегенерировать CSV и сметы.

## Решения, которые принял агент (проверить владельцу)

1. Цены пакетов — 69 / 99 / 159 / 209 / от 229 тыс. ₽. «Старт» в середине рынка (студии 75–130 тыс.), пакет для селлеров дороже студий, но включает синхронизацию с 2 площадками.
2. Этап 0 платный (15 000 ₽, засчитывается) — по исследованию и принципу агентства «диагностика первой».
3. Коэффициент стандартизации пакетов 0,85 — гипотеза, проверить по таймеру.
4. Кейсы на лендинге — только после подтверждения цифр и разрешений клиентов.
