# Шортлист тем InSales по нишам (DSN-01)

Норма DSN-01 — 0,5 ч: клиенту показываем 2–3 темы из этого списка, а не весь каталог. Список собран 06.10.2026 по сниппетам поиска (каталог insales.ru закрыт прокси). Перед первым проектом в нише открыть демо каждой темы и заполнить колонку «проверено».

## Как выбираем

1. Ниша → строка таблицы ниже, 1 бесплатная и 1–2 платные.
2. Проверяем функции до картинки: меню каталога на телефоне (HA-056, HA-061), фильтры, варианты товара, быстрый просмотр, блоки главной из брифа.
3. Только темы 4-го поколения: оформление заказа штатное, правки безопаснее. Старые темы и темы с чужим кодом не берём без анализа (GB-003, SK-002).
4. Платная тема дешевле доработки, если закрывает больше 4 ч работы по нашей ставке (≈10 000 ₽).
5. Клиент выбирает по функциям, а не по фото на демо: показываем демо со своими товарами-заглушками, если успеваем.
