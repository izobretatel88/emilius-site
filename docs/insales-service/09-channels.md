**Лучшие (делаем сразу):**

2. Своя база и рекомендации бывших клиентов.
3. Партнёры: внедренцы МойСклад/1С, фулфилменты, бухгалтеры селлеров.
4. Холодный поиск брендов на WB/Ozon (A2) — по 20 лидов в неделю.

**Перспективные (тест 4–8 недель):**
5. Яндекс Директ на поиск, бюджет теста 30 тыс. ₽.
6. Контент для селлеров: 2 статьи на vc.ru + пост в канале.
7. Биржи (Workspace, FL.ru).

**Экспериментальные:**
8. Офлайн-розница через Карты/2ГИС (C).
9. Бренды из VK/Telegram (B).
10. Совместные эфиры с сообществами.

**Слабые (не тратим время):**
- Массовые рассылки без персонализации — спам, вредит бренду.
- Перепродавцы без бренда (A1) — не окупают сайт.

- РСЯ и таргет на широкую аудиторию «предприниматели» — дорого, низкое намерение.

## Проспектинг: кого и как искать

### A2. Бренд или производство на WB/Ozon — главный сегмент

**Признаки (вручную):**
- Продавец на WB/Ozon — ООО/ИП с названием, совпадающим с брендом (не «ИП Иванов» с 30 брендами).
- 2+ площадки (WB + Ozon / Яндекс Маркет / СберМегаМаркет / Lamoda).
- Категория с повторными покупками: постельное бельё, косметика, бытовая химия, зоотовары, продукты, детские товары, расходники, чай/кофе, БАДы (осторожно: сертификация).
- Сайта нет / визитка на Tilda или orgs.biz / кнопки «купить на WB».
- Отзывы на МП: «а где ещё можно купить?», «нет нужного размера» — спрос на прямой канал.
- 30–500 SKU — наш размер.

**Как искать:**
1. WB/Ozon: поиск по категории → фильтр по бренду → карточка продавца → ИНН → название → поиск сайта.
2. Поиск Яндекса: `"официальный магазин" "wildberries" "ozon" -insales` по нише; `"купить на wildberries" site:tilda.ws`; `site:orgs.biz wildberries`.
3. Новости: «запустил бренд», «собственное производство», «вышел на маркетплейсы» + ниша.
4. Выставки (каталоги участников: «Текстильлегпром», «ПаркЗоо», «ИнтерШарм») — производства с брендами.

**Полуавтоматически:** таблица-шаблон (`Emilius · InSales · лиды`) + скрипт/агент проходит по списку брендов и проверяет: есть ли сайт, на чём (по HTML: `tilda.ws`, `myinsales`, `bitrix`), есть ли корзина, контакты. Человек проверяет только лиды с баллом ≥ 3.

### C. Офлайн-магазины и производители

- Яндекс Карты / 2ГИС: «зоомагазин», «магазин тканей», «кондитерская», «магазин рыболовных товаров», «пекарня», «магазин чая» + город-миллионник.
- Признаки: 2+ точки, много отзывов, нет сайта или сайт-визитка, в отзывах «есть ли доставка», «можно ли заказать заранее».
- Повод: вторая точка, сезон, вопросы в отзывах. Эталон — Happy Animal.

### B. Бренды из соцсетей

- VK: поиск сообществ по нише с разделом «Товары», 5–50 тыс. подписчиков, «заказ в сообщениях».
- Telegram: каналы-магазины с «оплата переводом», «пишите @…».
- Повод: «Видел, что заказы — в личку».

### D. Магазины, которым тесно на Tilda / старой CMS

- `site:tilda.ws` + ниша + «корзина»; магазины на `*.tilda.ws` без своего домена.
- Признаки: > 50 товаров, размеры/цвета, нет фильтров, нет своего домена, старая CMS (WordPress/OpenCart с устаревшим дизайном).
- Повод: конкретная проблема на сайте (нет фильтра по размеру, корзина не считает доставку).

## Скоринг лида для проспектинга (правило v2 от 06.10.2026, уточнено)

| Признак | Балл |
|---|---|
| Свой бренд или производство | +2 |
| 2+ площадки или 2+ офлайн-точки | +1 |
| Категория с повторными покупками | +1 |
| Нет сайта с корзиной / визитка / кнопки «купить на WB» | +1 |
| Каталог 30–1 000 SKU (видно или оценка) | +1 |
| Найден контакт ЛПР или рабочий канал (сайт, Telegram, почта) | 0 / нет контакта −2 |
| Перепродавец без бренда | −2 |
| Поддомен tilda.ws без бренда и продаж | −2 (не снимается, если есть производство и продажи на WB/Ozon) |

**≥ 4** — пишем в течение недели (приоритет 1); **3** — пишем после ручной проверки (2); **≤ 2** — не пишем, держим в базе (3). Максимум — 6.

## Норма работы

- 20 новых лидов A2/C в неделю, из них ~8 с баллом ≥ 3 → 8 первых сообщений.
- Ожидание (Г): 8 сообщений → 2 ответа → 1 созвон → 0,2 сделки в неделю → ~1 сделка в месяц из холодного канала. Плюс тёплые и горячие.
- План на месяц: 2–3 сделки (каталог партнёров + база + партнёры + холодный канал). При среднем чеке ~120 тыс. ₽ — 240–360 тыс. ₽ в месяц.
