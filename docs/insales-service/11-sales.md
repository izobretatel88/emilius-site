# 11. Продажи: квалификация, диалог, возражения, апсейлы

## Квалификация лида

### Пять вопросов (в переписке или первые 5 минут созвона)

1. **Где продаёте сейчас и примерно сколько заказов в месяц?** — есть ли спрос.
2. **Сколько товаров и в чём ведёте остатки?** — размер проекта, пакет.
3. **Откуда придут первые покупатели на сайт?** — есть ли канал.
4. **Кто будет обрабатывать заказы с сайта?** — есть ли ответственный.
5. **К какой дате и на какой бюджет ориентируетесь?** — срочность и деньги.

### Скоринг (0–10)

| Критерий | 0 | 1 | 2 |
|---|---|---|---|
| Спрос | Продаж нет | Есть, < 50 заказов/мес | ≥ 50 заказов/мес или 2+ точки |
| Бренд и повторы | Перепродажа, разовые покупки | Свой бренд или повторы | Свой бренд и повторы |
| Канал для сайта | Не знает | Подписчики или база | База + реклама/поиск/офлайн |
| Ответственный | Нет | «Сам буду» | Конкретный сотрудник |
| Бюджет и срок | < 50 тыс. или «бесплатно» | 50–100 тыс. | ≥ 100 тыс., дата с причиной |

| Балл | Решение | Следующий шаг |
|---|---|---|
| **8–10** | Горячий | Созвон-диагностика в течение 2 дней, КП в день созвона |
| **5–7** | Тёплый | Созвон; если есть «0» по каналу или экономике — предлагаем Этап 0 |
| **3–4** | Рано | Этап 0 или бесплатный материал (расчёт «площадка vs сайт»), возврат через 3 мес. |
| **0–2** | Не наш | Вежливо: KIT/Tilda/«рано», без продажи |

**Стоп-сигналы** (не продаём пакет, даже при деньгах): «нужна гарантия продаж»; нет ИП/ООО и не планируется; «сделайте как у [крупный ритейлер] за 50 тыс.»; нет ни одного человека на заказы и не будет.

## Логика диалога

```
Первое сообщение
  ├─ нет ответа → сообщение 2 → follow-up 3 → пауза 3 мес.
  ├─ отказ → «спасибо» + причина в таблицу → новый повод через 3–6 мес.
  ├─ возражение → ответ из 10-outreach.md → вопрос-цифра
  └─ интерес
       → квалификация (5 вопросов) → скоринг
           ├─ 0–2 → вежливо не продаём
           ├─ 3–4 → Этап 0 / материал
           └─ 5–10 → созвон-диагностика (30–60 мин)
                 → ситуация → проблема → последствия → желаемый результат
                 → калькулятор на экране → вилка цены
                     ├─ в пакете → КП «пакет + допы» в тот же день
                     ├─ смета > 150 тыс. или 1С/переезд → Этап 0 (15 тыс., засчитывается)
                     └─ сомнение «нужен ли сайт» → Этап 0
                 → договор → предоплата → старт
```

## Созвон-диагностика (30–60 минут)

| Минуты | Шаг | Что говорим / спрашиваем | Цель |
|---|---|---|---|
| 0–3 | Рамка | «Полчаса: я спрашиваю про ваш бизнес, в конце называю цену и что входит. Если окажется, что магазин сейчас не нужен, — так и скажу. Ок?» | Снять напряжение «мне будут продавать» |
| 3–12 | Ситуация | Где продаёте, сколько заказов, средний чек, повторы, кто работает с заказами | Факты для брифа |
| 12–20 | Проблема | «Что подтолкнуло думать о сайте именно сейчас?», «Что было в тот день?», «Что уже пробовали?» | Найти событие-триггер, его словами |
| 20–25 | Последствия | «Что будет, если через полгода всё останется как сейчас?», «Сколько стоит это в месяц — комиссии, часы на переписку?» | Цена бездействия в рублях и часах |
| 25–30 | Результат | «Как через 3 месяца поймёте, что сделали правильно?» | Критерий успеха = будущий отчёт 30 дней |
| 30–45 | Объём | Анкета (каталог, учёт, оплата, доставка) — сразу в калькулятор | Бриф |
| 45–55 | Предложение | Показываем пакет, допы, срок, расходы в месяц. «Что из этого лишнее? Что непонятно?» | Согласовать объём |
| 55–60 | Следующий шаг | «КП пришлю сегодня до 18:00. Когда созвонимся решить — завтра или в четверг?» | Дата, а не «подумаю» |

**Главное правило:** не рассказывать про агентство больше двух минут. Клиент должен говорить 60% времени.

## Основные ветки

**Селлер с брендом, 2 площадки, без учёта.**
Боль — двойная работа и зависимость. Предложение — «Магазин + синхронизация» через InSales или МойСклад как центр (если 2+ площадки и растут). Этап 0 входит: расчёт «площадка vs сайт» на его SKU. Апсейл — брошенная корзина, Директ на брендовые запросы.

**Офлайн-магазин с 1С.**
Боль — заказы по телефону, «а есть в наличии?». Предложение — смета (1С вне пакетов), Этап 0 обязателен: проверить конфигурацию и программиста 1С. Апсейл — локальное SEO, Яндекс Бизнес, самовывоз из точек.

**Бренд из соцсетей, до 50 товаров.**
Боль — переписка. Предложение — «Старт». Если < 20 товаров без вариантов — честно советуем KIT/Tilda (доверие → рекомендации). Апсейл — описания и фото, рассылки.

**Магазин на Tilda.**
Боль — нет фильтров/вариантов/остатков. Предложение — «Магазин» + модуль «Переезд» (смета). Если трафика из поиска нет — переезд упрощается до импорта товаров. Апсейл — e-commerce, SEO.

**«Хочу магазин, продаж ещё нет».**
Не продаём пакет. Предлагаем Этап 0 или бесплатный совет: сначала проверить спрос на МП или в соцсетях.

## Возражения и ответы

| Возражение | Что за ним обычно стоит | Ответ |
|---|---|---|
| «Дорого» | Сравнивает с фрилансером или не видит окупаемости | Сравнить составы по пунктам; предложить «Старт» с ростом без переделки; Этап 0 для расчёта окупаемости |
| «Фрилансер сделает за 25 тысяч» | Не видит разницы | «Попросите у него список: документы, чеки 54-ФЗ, расчёт доставки, тестовые заказы, обучение, гарантия. Если всё есть — хороший вариант» |
| «Нам хватает маркетплейсов» | Нет боли или не посчитано | «Какая доля повторных покупателей? Если мало — сайт не нужен, и это нормально» |
| «Боимся, что не будет продаж» | Страх пустого сайта | План первых 100 заказов на Этапе 0; отчёт 30 дней; не обещаем, а считаем |
| «У нас уже есть сайт» | Не хочет переделывать | «Сколько заказов с него в месяц? Что мешает?» → решение настройкой или переезд |
| «Сделаем сами / KIT бесплатный» | Экономия | Согласиться для маленьких каталогов; показать, где начинается наша зона (варианты, учёт, синхронизация) |
| «Потом будете доить доработками» | Плохой опыт | Прайс допработ до договора; фиксированный состав в ТЗ кодами работ; гарантия 14 дней |
| «InSales дорожает» | Страх стоимости владения | Расходы в месяц считаем до договора и пишем в паспорт; всё на ваших аккаунтах, переезд возможен |
| «Нет времени этим заниматься» | Нет ответственного | «От вас — 3 часа: созвон, таблица товаров, обучение. Но человек на заказы нужен — кто это будет?» |
| «Давайте после сезона» | Откладывание | Запуск к сезону — за 6–8 недель; предложить дату напоминания |
| «Нужно посоветоваться с партнёром» | Второй ЛПР | «Давайте созвонимся втроём на 20 минут — отвечу на все вопросы» |
| «Можно без предоплаты?» | Недоверие | Этап 0 как маленький первый шаг; кейсы и отзывы в каталоге партнёров InSales |

## Апсейлы по моментам

| Момент | Что предлагаем |
|---|---|
| Созвон-диагностика | Этап 0; пакет выше, если каталог на границе лимита; e-commerce при планах рекламы |
| КП | 2 варианта: «Пакет» и «Пакет + рекомендуемое» (рассылки, фиды, отчёт 30 дней) |
| Сборка | Описания и фото, если клиент тянет с материалами (K09, K10) — снимает задержку |
| Сдача | Пакет поддержки 5/10/20 ч; отчёт 30 дней |
| День 30 | Директ на брендовые запросы, SEO, программа повторных покупок, касдев покупателей |
| Месяц 3 | Индивидуальные доработки, новые площадки, переход на «Магазин + синхронизация» |

## КП: структура (одна страница)

1. Ваша ситуация — 2 строки его словами.
2. Что сделаем — пакет и допы списком.
3. Цена и срок — одна цифра и дата запуска.
4. Что будет стоить в месяц — тариф, приложения, эквайринг.
5. Когда считаем готовым — 5 критериев.
6. Что не входит.
7. Следующий шаг — «Договор и счёт пришлю после вашего “да”, старт — [дата]».

## Воронка и нормы (Г, проверить за 8 недель)

| Шаг | Конверсия |
|---|---|
| Первое сообщение → ответ | 20–25% (холодные), 50%+ (тёплые) |
| Ответ → созвон | 40% |
| Созвон → КП | 80% |
| КП → оплата | 30–40% |
| Этап 0 → пакет | 60% |
