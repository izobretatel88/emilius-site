# 10. Улучшение продукта

## Метрики воронки (вести в таблице лидов)

визиты/касания → ответы → квалифицированные (балл 5+) → бриф-созвоны → этапы 0 → договоры → запуски → первые заказы клиента → повторные проекты/подписки.

| Метрика | Цель v1 (гипотеза) | Как считать |
|---|---|---|
| Ответ на холодное сообщение | 10% | ответы / отправленные |
| Квалифицированный из ответивших | 30% | балл 5+ / ответы |
| Созвон → смета/этап 0 | 60% | |
| Смета → договор | 30% | |
| Факт часов / норматив | 0,9–1,15 | по проекту, по каждому коду работы |
| Маржа проекта | ≥ 30% к себестоимости | выручка / Σ (факт часов × ставка выплаты) |
| Клиент через 30 дней купил часы/подписку | 30% | |

## После каждого проекта (15 минут)

1. Выгрузить факт часов из Weeek по кодам работ (теги задач = коды из `works.csv`).
2. Код, где факт / норматив > 1,3 два проекта подряд → поднять норматив. < 0,7 → снизить.
3. Новая работа, которой нет в каталоге → добавить строку.
4. Записать последнюю каплю клиента и первую поисковую фразу в 01-research.md (раздел «Язык клиентов»).
5. Если клиент разрешает — кейс с цифрами.

### v1 — 07.10.2026

**Сделано:** база знаний из исследования ЦА; каталог 80 работ с нормативами; калькулятор `scripts/insales-estimate.mjs`; пакеты, сверенные калькулятором; бриф с привязкой к полям; процесс из 17 этапов с чек-листами; карточка услуги; лендинг с текстами; каналы с рейтингом; скоринг v3; сценарии по 4 сегментам; диалог и возражения.

**Проверка и что изменили в той же итерации:**
- Первый расчёт «Старта» дал 120 тыс. ₽ (43,6 ч) — дорого для малого бизнеса. Стандартизировали 7 работ (юр. страницы по шаблонам, служебные страницы, SEO-база, гарантия) → 37,9 ч, 105 тыс. ₽ по калькулятору, пакет 99 тыс. ₽.
- Строки сметы шли вперемешку по блокам — отсортировали по порядку каталога.
- Скоринг v2 штрафовал за поддомен tilda.ws, из-за чего лучшие лиды A2 получали 3 вместо 5–6. В v3 поддомен — признак потребности, штраф только за отсутствие контакта.
- Прогон 06.10: 10 из 16 лидов — Tilda-магазины без подтверждённого бренда с баллом 0. Порядок проспектинга изменён: начинать с брендов на WB/Ozon, а не с поиска по tilda.ws.

**Слабые места v1:** цены не сверены с рынком; нормативы — экспертная оценка, не факт; ставки N, Q, K, A — допущения; нет кейса шаблонного запуска.
