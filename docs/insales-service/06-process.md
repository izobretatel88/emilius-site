## Документы процесса (шаблоны создать один раз)

1. Чек-лист материалов клиента — `S3`.
2. Шаблон таблицы импорта — `C4`.
3. Отчёт Этапа 0 (1 страница + смета года).
4. КП — раздел в `07-service-card.md`.
5. Протокол тестов (чек-лист приёмки) — ниже.
6. Памятка владельца — `Q3`.
7. Видео-библиотека: «Как принять заказ», «Как добавить товар», «Как изменить цену и остаток», «Как сделать промокод», «Как поменять баннер», «Что делать, если не пришёл заказ».
8. Отчёт «Первые 30 дней».

## Чек-лист приёмки (протокол тестов)

- [ ] Главная, каталог, карточка, корзина, оформление — на 375 px и на компьютере
- [ ] Фильтры дают правильный результат, сортировка работает
- [ ] Товар с вариантами: выбор размера меняет цену и остаток
- [ ] Регистрация и вход не сбрасывают корзину
- [ ] Каждый способ оплаты: оплата, чек прихода, возврат, чек возврата
- [ ] Каждый способ доставки: расчёт цены, пункт выдачи на карте, бесплатная доставка от суммы
- [ ] Письма покупателю и магазину приходят, не в спаме
- [ ] Уведомление о заказе в Telegram приходит
- [ ] Согласие на ПД отдельным чекбоксом, без галочки по умолчанию; cookie-уведомление
- [ ] Оферта, политика, реквизиты в подвале
- [ ] Метрика: цели корзины, оформления, покупки; e-commerce показывает выручку тестового заказа
- [ ] Маркетплейсы: изменили остаток на МП — изменился на сайте (и наоборот, если настроено)
- [ ] 1С/МойСклад: тестовый заказ дошёл в учёт, остаток списан
- [ ] Перенос: 20 случайных старых URL отдают 301 на правильные страницы
- [ ] Домен открывается без www и по https, старые адреса редиректят
- [ ] robots.txt не закрывает сайт после открытия
