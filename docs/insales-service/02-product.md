# 2. Продукт: архитектура услуги и цены

## Формулировка

**«Свой интернет-магазин на InSales за 3–5 недель — рядом с маркетплейсами, а не вместо них».**

Готовый шаблон InSales в цветах бренда, товары с площадки или из таблицы, оплата, доставка, касса, аналитика. Сдаём после трёх тестовых заказов. Цена фиксируется до старта по нормативам.

Обещаем рабочий магазин, в котором можно купить. Продажи не обещаем: трафик — отдельная работа, и мы говорим об этом на первом созвоне.

## Принципы

1. **Модули, а не «всё индивидуально».** Каждая работа — строка в [`data/works.csv`](data/works.csv) с нормативом часов. Смета — сумма строк.
2. **Этап 0 обязателен** для всего, что сложнее «Старта». Он платный и засчитывается в проект.
3. **Фикс-цена на объём из сметы.** Новое — отдельной сметой по тем же нормативам. Риск-буфер 10% уже заложен.
4. **Всё оформлено на клиента**: аккаунт inSales, домен, эквайринг, кабинеты. Это наш ответ на страх «подрядчик держит доступы».
5. **Шаблон не ломаем.** Правки темы — в её копии, каждая правка в паспорте магазина. Сильная кастомизация — уже не этот продукт, а разработка на час команды.

## Как считается цена

```
цена = округл_вверх_до_5000( Σ (часы_работы × ставка_роли) × Π коэффициентов )
часы_работы = h_fix + h_unit × количество
```

| Роль | Код | Ставка v1 | Источник |
|---|---|---|---|
| Разработчик inSales | R | 3 500 ₽ | фреймворк Emilius, дек. 2025 |
| Основатель / продажи | M | 3 500 ₽ | = ставка команды |
| Настройщик / проджект | N | 2 400 ₽ | допущение = ставка дизайна |
| Дизайнер | D | 2 400 ₽ | фреймворк |
| Аналитик / SEO / маркетолог | A | 2 400 ₽ | допущение |
| Тестировщик | Q | 2 400 ₽ | допущение |
| Контент-ассистент | K | 1 200 ₽ | допущение, аутсорс |

| Коэффициент | Когда | Значение |
|---|---|---|
| Риск-буфер фикс-цены | всегда | ×1,10 |
| Срочность | запуск быстрее срока из калькулятора | ×1,25 |
| Материалы не готовы | нет таблицы, фото или текстов на старте | ×1,15 |
| Много согласующих | 3+ человека со стороны клиента | ×1,10 |

**Срок** = часы × коэффициенты / 5 чистых часов в день + 3 дня ожидания клиента на каждые 20 часов.

**Класс проекта:** S — до 120 тыс. ₽ без интеграций; M — до 250 тыс. ₽; L — дороже. L продаём только через этап 0 и с поэтапной оплатой.

**Оплата:** 50% предоплата, 50% после приёмки тест-заказов (соответствует колонке «процент предоплаты 50%» в финансовой таблице агентства). Для L — 30/40/30 по этапам.
