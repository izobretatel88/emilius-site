# 02. Архитектура услуги

**Название для клиента:** «Свой интернет-магазин на InSales — рядом с маркетплейсами».
**Внутреннее название:** услуга ISHOP (магазин на готовом шаблоне InSales).

**Обещание:** за 3–6 недель запускаем магазин на готовом шаблоне InSales, где товары, остатки и заказы связаны с маркетплейсами или учётом, а оплата и доставка проверены тестовыми заказами. Площадки продолжают работать как раньше.

**Не обещаем:** продажи и выручку. Обещаем рабочий магазин, измеримый запуск и план первых заказов.

## Лестница предложения

```
Этап 0 «Диагностика»  →  Пакет запуска  →  Опции  →  Разбор 30 дней  →  Сопровождение (часы/месяц)
   15 000 ₽                от 69 000 ₽                                     от 133 000 ₽ / 40 ч
 (засчитывается)
```

## Этап 0 «Диагностика и план» — 15 000 ₽

Платный вход, засчитывается в стоимость проекта, если договор подписан в течение 14 дней.
Состав (работы S0.01–S0.06, ~5,5 ч продакта): разговор по брифу, разбор текущих каналов, расчёт стоимости владения магазином на 12 месяцев и порога окупаемости, выбор тарифа InSales, 2–3 шаблона, смета из калькулятора с границами объёма.
Для сегмента без своей аудитории + план «откуда первые 100 покупателей» (S0.07). Для 1С — аудит конфигурации (S0.08).

**Результат:** клиент получает решение «делать / не делать / делать позже», цену и срок. Отказ после этапа 0 — нормальный исход: клиент платил за ответ, а не за обещание.

## Что не входит никогда (и пишется в договоре)

- Подписка InSales, платный шаблон (обычно 20–25 тыс. ₽), платные приложения.
- Комиссии платёжного сервиса, касса/ОФД, договоры со службами доставки — заключает клиент, мы помогаем с заявками.
- Работы 1С-программиста на стороне 1С.
- Реклама и бюджет на неё, фотосъёмка, юридическая проверка текстов.
- Кастомная разработка вне шаблона сверх оплаченных опций.

## Апсейлы (по ходу проекта)

| Когда | Что предложить | Почему клиенту выгодно |
|---|---|---|
| На этапе 0 нет источника трафика | Директ на запуск / SEO-структура | Без трафика магазин пустой |
| При импорте данные «грязные» | Чистка данных | Иначе фильтры не работают |
| Нет фото на белом фоне / описаний | Обработка фото, описания | Карточки МП не годятся для сайта |
| Покупатели повторяются | Бонусы + email-цепочка | Повторные заказы — главная экономика сайта |
| Продают оптом | Опт-кабинет | Один сайт на розницу и опт |
| После запуска | Сопровождение 40 ч/мес (133 тыс. ₽, −5%) | Развитие итерациями по данным |

## Кросс-сейлы (другие услуги Emilius)

Яндекс Директ на запуск; SEO-продвижение; дизайн UX/UI под кастомную тему; Tilda-лендинг для отдельной коллекции; ИИ-ассистент для ответов покупателям; доработки на Liquid для зрелых магазинов (опыт: alohagaia.ru, duman.store, geekboards.ru).
