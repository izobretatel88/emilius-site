## Честные оговорки

- Общемосковские запросы («стрижка собак в москве», «груминг кошек», «груминг салон москва») — вне топ-100. Кейс про местное SEO, не про Москву целиком.
- 12.09.2026 по местным запросам в выдаче была главная (`http://happyanimal.pet`), с 30.09 — новые страницы услуг. Ранние съёмы (02.09) показывают «нет в топ-100», но тогда проверка шла до переноса сайта — как точку «было» их не используем.
- «зоомагазин метро щелковская» — 21-я позиция в Яндексе. Ближайшее метро — «Черкизовская» (созвон с клиентом 15.09), запрос оставлен до решения по кластеру.
- Google по запросу «зоомагазин гольяново» показывает «О компании» и «Контакты», а не главную.

## Как обновить

Свежий съём в Топвизоре платный (около 40–50 ₽ за проект). Запускать — по решению владельца. После съёма выгрузить историю (`get/positions_2/history`, регионы 1, 33, 2, 30) и поправить таблицу выше и `FRESH_SHOP`.
Ключ API лежит в связке ключей macOS, в репозиторий не попадает.
