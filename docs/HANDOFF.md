## Как устроен деплой

- `.github/workflows/deploy.yml` запускается из `main` и собирает **обе** ветки: `main` в корень превью, `dev` — в подпапку `/dev/`.
- Пуш в `dev` запускает `dev-trigger.yml`, который дёргает деплой из `main` (окружение `github-pages` разрешает публикацию только из `main`, настройки репозитория не трогали).
- Превью собирается с `PREVIEW=1`: `noindex` + `robots.txt` с `Disallow: /`, чтобы не конкурировать с emilius.agency в поиске.
- GitHub Pages раздаёт новую версию с задержкой до ~2 минут после успешного деплоя (кеш `max-age=600`). Проверять с `?n=<время>` в адресе.
- Продакшен позже — Бегет: `SITE_URL=https://emilius.agency BASE_PATH=/ npm run build`, содержимое `dist/` (вместе со скрытым `.htaccess`) в корень хостинга. Подробно — `README.md`.

## Грабли и как их обходить

- **Pencil / pen.dev**: `.pen` читать и менять только через MCP `pencil` (файлы зашифрованы). Работает только с файлом, открытым в приложении. SVG как заливку не показывает — PNG логотипов клиентов лежат в `design/assets/projects/`. Импорт целой страницы из браузера зависает — импортировать частями (`header.hero`, колонки по отдельности). После правок через MCP файл «Edited» — просить владельца нажать ⌘S.
- **Claude Code CLI** для Pencil-агента установлен в `~/.local/bin/claude` (официальный установщик), вход выполнен через аккаунт claude.ai.
- **GitHub CLI** авторизован (`gh auth status`). Интерактивные запросы в панели терминала у владельца не принимают ввод — если понадобится, отвечать через `expect` (так проходили `gh auth login`).
- **Панель браузера**: если вкладка в фоне (`document.visibilityState === 'hidden'`), браузер замораживает анимации и `requestAnimationFrame` — проверки колеса и заставки дают ложные «зависания». Перед проверкой анимаций — `tabs_select`, смотреть `visibilityState`.
- **Дев-сервер vs сборка**: дев-сервер иногда держит старые стили в кеше вкладки — сверять по собранной версии (`npx astro preview --port 4322`).
- **macOS**: нет утилиты `timeout`; zsh не разбивает строки по словам в `for` — перечислять аргументы явно.
- **Звук**: браузеры не играют звук без действия человека — поэтому «Дай пять»; без клика `playSting` сам отказывается (контекст «suspended»), чтобы звук не заиграл невпопад.
