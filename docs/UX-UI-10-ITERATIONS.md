## Общая проверка

- Все десять проходов собраны по отдельности перед следующим.
- Финальный preview: 26 страниц, 1 445 проверенных внутренних ссылок. Production-сборка: 24 страницы, 1 306 ссылок; черновики исключены.
- Проверки расчётов InSales и механический детектор оформления прошли. Повторный импорт сравнений сохраняет изменения.
- В браузере проверены 320, 390, 768 и 1280 px, светлая и тёмная темы. Логотип остаётся по центру; удалённое меню над готовыми решениями не возвращено.
- Выбранные параметры калькулятора перенесены в заявку (social / 600 товаров); имя и контакт пусты, согласие не отмечено. Данные через формы не отправлялись.
- На проверенном переходе калькулятор → заявка ошибок JavaScript нет. Фактическая отправка и сетевой тайм-аут проверены только по коду, без обращения к рабочему получателю.

Публикация — только dev; производство выпускается отдельно по решению владельца.
