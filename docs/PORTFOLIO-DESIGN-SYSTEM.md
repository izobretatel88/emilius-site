# Портфолио Emilius: дизайн-система

> **Версия 1 от 19.11.2026.** Часть общей дизайн-системы (`docs/EMILIUS-DESIGN-SYSTEM.md`): цвета, шрифт, радиусы, движение и голос — оттуда. Здесь — то, что относится только к показу работ: превью, карточка проекта, видео, окно просмотра, подписи и съёмка материалов.
> Источник истины — код: `src/components/ProjectPreview.astro`, `src/styles/portfolio.css`, `src/lib/preview-video.ts`, `src/lib/project-viewer.ts`, `scripts/record-gallery.mjs`, токены в `src/styles/tokens.css`.
> Аудит, на котором она основана, — `docs/PORTFOLIO-AUDIT-2026-11-19.md`.

---

## 0. Суть в пяти строках

1. **Работа говорит первой.** Превью — живой сайт клиента: снимок, который при наведении (на телефоне — сам) становится прокруткой сайта. Интерфейс вокруг — тихий.
2. **Одна карточка проекта везде:** галерея `/projects/`, главная, страницы направлений. Белая плитка, превью 8:5 с полем 10 px, подпись под ним.
3. **Снимок — первый кадр видео.** Переход «снимок → видео» без шва, дата съёмки видна, живой сайт мог измениться.
4. **Доказательство до действия:** что сделали → цифра (если есть и подтверждена) → «Хочу похожий…».
5. **Спокойно:** проявление 0,2 с, одно видео за раз, на телефоне — один раз, без звука, при «уменьшении движения» — снимок.

## 2. Токены портфолио

Живут в `src/styles/tokens.css`, раздел «Портфолио». Новых цветов портфолио не вводит.

| Токен | Значение | Где |
|---|---|---|
| `--preview-ratio` | `8 / 5` | Пропорция превью и записи (1280×800, снимок 1600×1000) |
| `--preview-edge` | `0 0 0 1px var(--hair)` | Тонкая линия по краю превью: светлый сайт (LimeMart) не растворяется в белой карточке |
| `--project-inset` | `10px` | Поле карточки вокруг превью; на телефоне 8 px |
| `--img-dim` | `none` / тёмная тема `brightness(0.88)` | Снимок **и** видео — одинаково, иначе видео вспыхивает ярче |
| `--fade-in` | `0.2s cubic-bezier(0.23,1,0.32,1)` | Проявление видео |
| `--hover` | `0.2s ease-in-out` | Уход видео, смена цвета плашки |
| `--press`, `--press-scale-card` | `0.16s …`, `0.99` | Нажатие на превью — плитка едва проседает |

Радиусы: карточка `--radius-card` (20), превью внутри карточки `--radius-sm` (10), плашка `--radius-btn` (13).

## 3. Компоненты

### 3.1 Превью проекта — `ProjectPreview.astro`

```
<ProjectPreview href label image={{src, srcset, sizes, width, height, alt, eager}}
                video={{src, small}} action="Смотреть проект" arrow whole />
```

| Часть | Правило |
|---|---|
| Ссылка | Вся плитка — одна ссылка. `aria-label` называет действие и проект: «Смотреть проект Aloha Gaia» |
| Снимок | 8:5, `object-fit: cover`, `object-position: top`. Первый на странице (крупная карточка галереи) — `eager` и `fetchpriority=high`, остальные — `lazy` |
| Видео | Поверх снимка, прозрачное до первого кадра. `preload="none"`, `muted`, `playsinline`, `aria-hidden`, вне табуляции. Источник ставится только перед первым показом |
| Плашка | Белая, r13, справа внизу 14 px (телефон 10), 13 px / 600. Наведение, фокус, касание — заливается `--teal-btn` |
| `whole` | Запись шире 8:5 (Marine Garden, 1440×774) — целиком, по центру серого поля, без обрезки |
| Нажатие | `scale(var(--press-scale-card))` за `--press`; при «уменьшении движения» — без масштаба |

### 3.2 Карточка проекта — `.project-card`

Анатомия сверху вниз (обязательное **жирным**):

1. **Превью** (3.1).
2. Ниша — 13 px, `--ink-2` («Доставка продуктов»). В галерее.
3. **Название** — H2 галереи 28 px (крупная карточка — `--fs-h2`), H3 главной и направлений — `--fs-h3`.
4. **Что сделали** — основной кегль, `--ink` («Фронтенд на inSales», «Дизайн · разработка · маркетинг · вайбкодинг»).
5. Метка этапа (`.ui-stage-tag`) — только по данным `cases` направления.
6. Адрес сайта ↗ — если сайт открыт; новая вкладка.
7. Результат — только подтверждённая цифра с источником и датой (LimeMart «2000+ заказов в месяц», Happy Animal «5 из 5 запросов в топ-5 Яндекса · 01.10.2026 · Топвизор»). Нет цифры — нет строки.
8. **«Хочу похожий магазин / сайт»** — на всех трёх поверхностях, прижато к низу: в ряду карточек стоит на одной линии. Текст — только из `similarLabel(id)` (`src/lib/project-inquiry.ts`): интернет-магазин → «магазин», лендинг или сайт → «сайт». Ссылка `?project=id#feedback`: форма заполнится, заставка не всплывёт.

Поля: подписи отступают на 16 px от края (телефон 10), первая — на 20 px от превью (телефон 16). Карточка — `--card`, без обводки, `--shadow-card`; в тёмной теме без тени.

### 3.3 Окно просмотра — `project-viewer.ts`

| Элемент | Правило |
|---|---|
| Открытие | Только из галереи, по превью. Ссылка на снимок работает и без JS |
| Переключатели | Два независимых: вид «Компьютер / Телефон» и формат «Снимок / Видео». Нет формата у вида — окно берёт тот, что есть, лишняя кнопка прячется |
| Масштаб | «По ширине / 100%» — только у снимка компьютера, и только если снимок не помещается |
| Видео | С кнопками плеера, без звука, по кругу. Постер — тот же снимок: «Снимок → Видео» без скачка. При «уменьшении движения» ждёт «Пуск» |
| Заголовок | Название и под ним — что сделали (роль из подписи карточки), 13 px `--ink-2` |
| Подпись | «Снято ДД.ММ.ГГГГ. Живой сайт мог измениться: домен» — у каждого снимка и видео своя дата. Нет адреса сайта — только дата |
| Закрытие | Кнопка «Закрыть ×», Esc, клик по фону. Видео останавливается на любом пути закрытия |
| Действие | «Хочу похожий магазин / сайт» — текстовая ссылка справа в панели; подпись — `similarLabel(id)` из `src/lib/project-inquiry.ts` |

### 3.4 Плашка «Следующий проект» в галерее

Последняя плитка: «Покажем здесь и ваш сайт?» + одна залитая кнопка. При нечётном числе карточек растягивается на ряд.

## 4. Поведение видео — `preview-video.ts`

| Где | Когда играет | Когда останавливается |
|---|---|---|
| Компьютер (мышь) | Курсор задержался 150 мс | Курсор ушёл. Конец ролика — гаснет до снимка и повторяет, пока курсор над превью |
| Клавиатура | Фокус с клавиатуры (`:focus-visible`) | Фокус ушёл |
| Телефон, планшет | Прокрутка остановилась 400 мс, превью видно на 70%+, ближе всех к середине экрана | Ушло с экрана. Один раз за показ (WCAG 2.2.2): проиграло — гаснет до снимка |
| Везде | — | «Уменьшение движения», экономия трафика, вкладка свёрнута, нажатие на превью |

- Одновременно играет **одно** видео.
- Лёгкая копия 640 px — телефону и узким превью; компьютеру — по физическим пикселям (Retina получает 1280).
- Без наведения страница не грузит ни одного видео.

## 5. Материалы: съёмка и файлы

| Файл | Размер | Как получен |
|---|---|---|
| `public/video/gallery/{id}.mp4` | 1280×800, 10–19 с, CRF 30 | `node scripts/record-gallery.mjs {id}` |
| `public/video/gallery/{id}-640.mp4` | 640×400, CRF 31 | Тот же запуск |
| `public/cases/gallery/{id}-1600.webp`, `-800.webp` | 1600×1000 / 800×500 | Первый кадр той же записи, без потерь |
| `public/video/gallery/phone/{id}.mp4`, `.webp` | 780×1328 (iPhone 13, 2×) | `node scripts/record-gallery.mjs --phone {id}` |
| `public/cases/mobile/{id}.webp` | 520 px | Мобильные снимки владельца (каталог) |

Правила записи (в скрипте):

- Прокрутка плавная (ease-in-out), секунда на первом экране и в конце, не дальше 5600 px.
- Всплывающие окна (cookie, город, промокод, согласие) — **скрываются, не нажимаются**. Текст сайта не подменяется.
- Карусели стоят на первом слайде (`freezeSliders`). Нажимается только кнопка воспроизведения главного видео сайта, если оно не идёт само (`PLAY`, Навалишенское) — запись с начала ролика.
- Ленивая загрузка прогревается проходом по странице; видео на первом экране сайта — ждём, пока пошло.
- Пересняли — обновили дату в `shotDates` / `videoDates` в `src/pages/projects/index.astro`.

## 6. Тексты карточки

- Формула: **ниша → что сделали → цифра → действие**. Ниша — существительным («Доставка продуктов», «Апарт-отель в Сочи»), без «Интернет-магазин на inSales для…».
- «Что сделали» — роли через « · »: «Дизайн · разработка · маркетинг · вайбкодинг».
- Цифра — только с источником и датой, иначе строки нет (общее правило §10 дизайн-системы).
- `alt` снимка: «Главная страница сайта {Название}». Мобильный снимок — «Каталог {Название} на телефоне».
- Ссылки на сайт клиента — домен без `https://` и `www`, со стрелкой ↗ и пометкой «откроется в новой вкладке» для экранного диктора.

## 7. Доступность

- Превью — ссылка с понятным именем; плашка и видео скрыты от диктора (`aria-hidden`), имя несёт ссылка.
- Фокус — общее бирюзовое кольцо (`--focus-ring`); на превью фокус ещё и запускает видео.
- Цели касания — от 44 px: адрес сайта, «Хочу похожий…», кнопки окна.
- Движение: видео не играет при «уменьшении движения»; на телефоне — один раз; в окне — с кнопкой паузы.
- Окно — `<dialog>` с заголовком, группы переключателей с `aria-label`, `aria-pressed` у кнопок, фокус возвращается на превью.

## 8. Чего не делать

- Ещё одну копию разметки превью или CSS видео — только `ProjectPreview`.
- Снимок, снятый отдельно от видео: шов при проявлении.
- Автозапуск всех видео сразу или по кругу на телефоне.
- Звук.
- Цифры без источника, «+300%» без базы.
- Цвет этапа где-либо, кроме метки этапа.
- Нажатие на кнопки согласия и выбор города на сайтах клиентов при съёмке.
