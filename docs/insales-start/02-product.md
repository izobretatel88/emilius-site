# 2. Продукт и карточка услуги

## Название

Внутреннее: **«Старт на InSales»**. Для клиента: **«Свой интернет-магазин на InSales за 4–6 недель»**.

## Обещание

Запускаем магазин на готовой теме InSales и сдаём его, когда прошли три тестовых заказа с телефона и компьютера: товар с правильной ценой и остатком, оплата, доставка, письмо покупателю, заказ видно в Метрике. Площадки работают как раньше.

Мы **не обещаем** выручку и трафик: сайт — это канал, а людей на него приводит реклама, база клиентов или поиск. Это говорим на первом созвоне.

## Архитектура: этап 0 + пакет + модули

```
Этап 0 «План магазина» (15 000 ₽, 3–5 дней)
   ├─ решение «пока не нужно» → отказ с рекомендацией (честно, без продажи)
   └─ смета →  Пакет: Старт | Селлер | Бизнес
                  + модули из конструктора (03-constructor.md)
                  → Запуск → Сопровождение 2 недели → Подписка на развитие
```

### Этап 0 «План магазина» — 15 000 ₽

Диагностика каналов, экономика сайта на 12 месяцев в трёх сценариях (не делать / витрина / магазин), тариф и приложения InSales, тема, структура каталога, смета и график. Засчитывается в стоимость пакета при старте в течение 30 дней. Работы D01–D07.

Зачем платный: отсекает тех, кто «просто узнать», и даёт клиенту ценность даже при отказе. **Г:** доля перехода из этапа 0 в пакет ≥ 50%.

### Даунсейл: «Запуск с наставником» — 36 000 ₽

Для тех, кому пакет дорог, но готов делать сам: 15 часов NC — тариф, тема, оплата, доставка, юр. страницы, Метрика, 2 созвона по 1 часу, разбор ошибок. Товары и контент заводит клиент. Не даём при 1С и маркетплейсах.

## Карточка услуги

| Поле | Содержание |
|---|---|
| Кому подходит | Бизнес с уже работающим источником покупателей: продажи на МП, подписчики, офлайн-клиенты, старый сайт с трафиком. От 20 до 5 000 товаров. Есть человек, который будет обрабатывать заказы. |
| Кому не подходит | Нет продаж и нет плана привлечения (продаём только этап 0). Нужна нестандартная логика: конфигураторы, маркетплейс продавцов, сложный B2B с договорами — это индивидуальная разработка. Ждут, что сайт сам принесёт заказы без рекламы. Хотят «как у Lamoda» за бюджет Старта. |
| Проблема | Продажи держатся на чужой площадке или переписке: комиссия растёт, покупатель не ваш, заказы оформляются руками. |
| Результат | Работающий магазин на своём домене: каталог, оплата с чеком, доставка с расчётом, юридические страницы, Метрика с продажами, обученный сотрудник, паспорт магазина с доступами. |
| Состав | Пакет + модули, см. таблицу выше и `03-constructor.md`. |
| Этапы | Этап 0 → договор и предоплата 50% → материалы → платформа и тема → каталог → оплата и доставка → интеграции → тест → обучение → открытие → сопровождение 2 недели → доплата. Подробно — `05-process.md`. |
| Сроки | 3–10 недель. Самые частые задержки — модерация банка (3–10 дней) и материалы клиента. |
| Стоимость | Этап 0 — 15 000 ₽. Пакеты от 100 / 130 / 175 тыс. ₽. Оплата 50/50. |
| Расходы клиента вне сметы | тариф InSales, платная тема, эквайринг и касса, доставка, МойСклад/1С, домен. Показываем в смете отдельным блоком. |
| Дополнительные работы | Всё из конструктора сверх пакета по ставке команды: NC 2 400 ₽/ч, DEV 3 500 ₽/ч. |
| Ограничения | Работаем в рамках возможностей темы и приложений InSales. Правки кода темы блокируют её автообновление — фиксируем это в смете. Юридические документы — шаблон, не консультация. Гарантия 60 дней не распространяется на изменения платформы InSales. |
| Требования к клиенту | Один ЛПР. Ответ в течение рабочего дня. Аккаунт InSales, домен, договоры с банком и доставкой — на клиенте. Ответственный за заказы к запуску. |
| Материалы | Логотип в векторе, таблица товаров или доступ к МП, фото, тексты о компании, условия доставки/оплаты/возврата, реквизиты, доступы к регистратору домена, Яндекс ID. Чек-лист — `04-brief.md`. |
| Критерии готовности | 3 тестовых заказа прошли (телефон, компьютер, оплата + доставка), чек пришёл, остатки списались, заказ в Метрике с суммой, сотрудник сам оформил заказ и добавил товар, паспорт передан. |
| Частые вопросы | `07-landing.md`, блок FAQ. |
| Риски | Затяжка материалов; банк; грязные данные товаров; расширение объёма «пока делаете»; клиент без трафика разочарован. Ответы — `05-process.md`. |
| Апсейлы | Модули: перенос каталога, МойСклад/1С, маркетплейсы, макет Figma, тексты карточек, SEO-структура. После запуска: подписка на развитие 40–80 ч/мес, Директ, SEO, рассылки, A/B карточки. |
| Кросс-сейлы | Дизайн бренда и упаковки (команда «Лотус»), касдев покупателей (колесо: недели 01–13), контекстная реклама 2 400 ₽/ч, лендинги на Tilda. |

## Связь с колесом продукта

Магазин — сектор «Разработка» (недели 27–39). Этап 0 — короткий касдев, после запуска клиент переходит в «Маркетинг» и следующий круг: данные первых заказов → касдев → доработки. Подписка на развитие — это и есть годовой цикл колеса.
