## 8.3 Скоринг найденной компании (правило v3, развивает v2 от 06.10)

| Признак | Баллы |
|---|---|
| Свой бренд или производство | +2 |
| 2+ маркетплейса | +1 |
| Повторная категория (расходники, косметика, бельё, зоо, детское, еда) | +1 |
| Сайт без корзины / кнопки «купить на WB» / визитка | +1 |
| 50+ SKU | +1 |
| Найден контакт ЛПР или рабочий контакт компании | +1 (нет контакта → −1, не −2: контакт ищется после) |
| Поддомен tilda.ws при своём производстве и МП | 0 (сигнал потребности, не минус) |
| Поддомен tilda.ws без производства и МП | −2 |
| Перепродажа без бренда | −2 |

Писать при балле ≥ 4. 2–3 — в «наблюдение», проверить через месяц. **Изменение v3:** контакт не найден теперь −1 вместо −2, иначе лучшие бренды прогона 06.10 (YERRNA, EDELSON) получали 3 и терялись.

Поля таблицы лидов — те же, что в «Emilius · InSales · лиды (прогон 06.10.2026)», плюс колонка «сегмент из 8.2» и «дата следующего касания».

## 8.4 Ритм

- Ежедневно 30 мин: биржи и тендеры, ответы.
- Ежедневно 45 мин: 10 новых компаний в таблицу, 5–10 персональных первых сообщений.
- Еженедельно: 1 статья или разбор в канал; отчёт по воронке.
- Ежемесячно: обновление карточки партнёра, письмо клиентам о рекомендациях.

План на первый месяц: 200 найденных компаний → 100 сообщений → 8–10 ответов → 4–5 созвонов → 2 «Плана магазина» → 1 магазин. Плюс входящие из каталога и бирж.
