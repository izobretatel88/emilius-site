# 4. Бриф, квалификация и оценка проекта

Цепочка: **5 квалифицирующих вопросов (в переписке) → балл лида → бриф (20 вопросов, этап 0) → JSON → `calc.mjs` → смета.**

## 4.1 Квалификация лида — 5 вопросов, 2 минуты

Задаются в переписке до созвона. Каждый ответ даёт баллы.

| # | Вопрос | Баллы |
|---|---|---|
| Q1 | Где сейчас продаёте и примерно сколько заказов в месяц? | МП/офлайн/соцсети с заказами каждую неделю +2; редкие продажи +1; продаж нет 0 |
| Q2 | Сколько товаров и где они сейчас описаны (WB, таблица, 1С)? | 20–2 000 и есть файл/кабинет +2; описаны частично +1; нет 0 |
| Q3 | Откуда придут первые покупатели на сайт? | база/подписчики/реклама с бюджетом +2; «подумаем» +1; «сайт сам» 0 |
| Q4 | Кто будет обрабатывать заказы с сайта? | названо имя +1; 0 |
| Q5 | Какой бюджет закладываете на запуск? | ≥100 тыс. +2; 40–100 тыс. +1; <40 тыс. или «бесплатно» 0 |

**Решение:**

| Балл | Класс | Что делаем |
|---|---|---|
| 8–9 | Горячий | Созвон в течение дня, предлагаем этап 0 или сразу бриф, если всё ясно |
| 5–7 | Тёплый | Созвон, продаём этап 0 «План магазина» |
| 3–4 | Холодный | Отправляем материал «нужен ли вам свой магазин» + даунсейл «Запуск с наставником»; повтор через 30 дней |
| 0–2 | Не наш | Вежливый отказ с советом (KIT/Tilda/пока продавать на МП), в CRM как «не сейчас» |

Стоп-факторы (любой → не берём пакет): нужна нестандартная логика вне темы; более одного ЛПР без финального; срок «к пятнице»; требование гарантировать выручку.

Поле `json` — ключ для калькулятора.

| # | Вопрос | Варианты | json |
|---|---|---|---|
| 1 | Название, ниша, сайт/ссылки на МП | текст | `name` |
| 2 | Сегмент (заполняем мы) | A1 / A2 / B / C / D / E | `segment` |
| 3 | Сколько товаров (SKU с вариантами) к запуску? | число | `sku` |
| 4 | Сколько категорий? | число | `categories` |

| 6 | Есть размеры/цвета как варианты одного товара? Нужна таблица размеров? | да/нет | `variants`, `sizes_table` |

| 9 | Внешний вид | тема в редакторе / макет в Figma; бесплатная / платная тема | `design`: editor, figma; `theme`: free, paid |
| 10 | Сколько баннеров? Что хотите изменить сверх возможностей темы? | число; список правок → классифицируем малая/средняя/крупная | `banners`, `mods_small`, `mods_medium`, `mods_large` |
| 11 | Дополнительные страницы, блог | число, да/нет | `extra_pages`, `blog` |
| 12 | Оплата: онлайн? дополнительные способы (при получении, счёт, рассрочка)? Есть договор с банком? | да/нет, число | `online_payment`, `extra_payments` |
| 13 | Доставка: какие службы? Агрегатор? Известны веса товаров? | число, да/нет | `delivery_services`, `aggregator`, `weights_needed` |
| 14 | Учёт: ничего / МойСклад / 1С (какая конфигурация, есть ли специалист 1С)? | — | `accounting`: none, moysklad, 1c; `c1_customers` |
| 15 | Нужны общие остатки с маркетплейсами? Сколько площадок? | число | `marketplaces` |
| 16 | CRM, чат, телефония, рассылки, бонусы | да/нет | `crm`, `chat`, `telephony`, `email`, `loyalty` |

Дополнительно для экономики (этап 0, не в калькулятор): средний чек, маржа, доля повторных покупок, комиссия и логистика МП на заказ, бюджет на рекламу в месяц, размер базы с согласиями.

## 4.3 Как считается цена

1. Ответы → правила `scope()` в `calc.mjs` → список работ с количеством единиц.
2. Часы работы = база + за единицу × количество (`works.csv`).
3. Деньги = часы × ставка роли (NC 2 400, DEV 3 500, DS 2 400, AN 2 400, CO 1 500).
4. Коэффициенты проекта: материалы частично ×1,1, нет ×1,2; срочно ×1,25; несколько согласующих ×1,1.
5. Скидка пакета часов агентства: 40+ ч −5%, 80+ −10%, 120+ −15%, 160+ −20%.
6. Округление до 1 000 ₽, минимум 60 000 ₽ (кроме даунсейла).
7. Фикс с коридором ±30% от сметы. Часовой коридор показывает разброс по сложности работ.
8. Срок = чистые часы / 4 ч в день + ожидания (банк 5 дней, 1С 5 дней, материалы 5 дней).

```bash
node docs/insales-start/calc.mjs docs/insales-start/examples/seller.json --md
node docs/insales-start/build.mjs   # пересобрать конструктор и примеры
```

Новый клиент: скопировать `examples/start.json`, заполнить ответы, запустить с `--md`, вставить в КП.
