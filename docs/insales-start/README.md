## Быстрый старт

```bash
# смета для нового клиента: скопировать пример, заполнить ответы брифа
cp docs/insales-start/examples/start.json /tmp/client.json
node docs/insales-start/calc.mjs /tmp/client.json --md

# после правки works.csv
node docs/insales-start/build.mjs
```

## Решения, которые нужны от владельца

1. Цены пакетов: Старт от 100 000 ₽, Селлер от 130 000 ₽, Бизнес от 175 000 ₽, «План магазина» 15 000 ₽, даунсейл 36 000 ₽ — утвердить или поправить.
2. Ставка контент-оператора 1 500 ₽/ч (новая роль для заведения товаров и описаний) — кто исполнитель.
3. Минимальный проект 60 000 ₽.
4. Первый проект со скидкой 20% в обмен на кейс и отзыв — да/нет.
5. Отправлять ли исходящие от имени Эмиля и с какого контакта.
6. Верстать ли лендинг `/insales/` на сайте (в ветке `dev`).

## Принятые рабочие решения (можно пересмотреть)

- Продаём через платный этап 0, а не через бесплатное КП: отсев и ценность при отказе.
- Не обещаем трафик и выручку; критерий сдачи — 3 тестовых заказа и обученный сотрудник.
- Аккаунт InSales, домен и Метрика всегда оформлены на клиента.
- Только Яндекс Метрика (152-ФЗ с 01.07.2025).
- Нет массовых рассылок; исходящие — вручную по скорингу ≥ 4.
