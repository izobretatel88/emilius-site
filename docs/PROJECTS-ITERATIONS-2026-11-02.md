# Циклы улучшения страницы проектов — 2 ноября 2026

По команде владельца работаем только с `/projects/` и её контроллером просмотра. Другие страницы и общие компоненты не меняем. Цикл: аудит → исправление → проверка. Номер публичной итерации 5/15 не меняется.

## Ограничение проверки

В начале работы выполнена попытка открыть `/projects/` во встроенном браузере: `Local browser use is disabled in Work settings`. Поэтому ниже — аудит исходников, собранного CSS/HTML, данных и поведения контроллера в изолированных тестах, где они указаны. Это не визуальная проверка и не замена реального браузера. Все изменения требуют приёмочного просмотра после восстановления доступа.

## Цикл 1 — доступность и оформление просмотра

Аудит выявил:

- Созданные через createElement кнопки экранов не имеют атрибута scoped CSS Astro; селектор ожидал его и не оформлял кнопки. Стиль теперь ограничен родителем, а динамические кнопки выбираются через :global.
- Изображение с hidden после сетевой ошибки могло показываться: авторский display:block сильнее браузерного правила hidden. Добавлено явное img[hidden] display:none.
- Прокручиваемая область снимка не имела имени и остановки Tab. Добавлены region, подпись, tabindex=0 и внутренняя видимая рамка фокуса.

Проверка: production-сборка (21 страница, 1257 ссылок), тест данных галереи (6 проектов, 10 снимков), проверка скомпилированного селектора динамических кнопок и приоритета hidden, наличие именованной области прокрутки. Ошибок нет. Runtime/визуальная проверка не выполнена.

## Цикл 2 — масштаб и лишние элементы управления

Аудит: мобильное правило растягивало любое компьютерное изображение до 1100 px, даже исходник 640 px. У проектов с одним экраном и устройством показывались переключатели без выбора.

Исправление: по умолчанию снимок вписан в область без увеличения сверх размера исходника; режим 100% показывает настоящий размер с прокруткой. Для телефонного вида сохранён показ устройства целиком по ширине. Единственные варианты устройства/экрана скрыты, название экрана остаётся в статусе. Динамические кнопки связываются с областью изображения через aria-controls.

Проверка: сборка и данные галереи прошли. `node scripts/check-project-viewer.mjs` проверяет контроллер на объектах в памяти: Ctrl-click, переходы между тестовыми экранами, выбор масштаба/устройства, поздний load от прошлого снимка, ошибка и повтор, закрытие и возврат фокуса, скрытие одиночных вариантов. Второй экран Duman в тесте — синтетическая фикстура, в страницу не добавлен. Браузер и сеть тест не использует; визуальную проверку не заменяет.
