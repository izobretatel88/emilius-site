Посыл

Агентство, которое работает циклами

Сайт почти ничего не рассказывает словами. Метод показывает объект: медленное колесо, где год разбит на четыре квартала и в центре стоит внимание.

Миссия

Партнёр, а не подрядчик

«Великолепные люди» — это клиенты. Агентство помогает им, но не присваивает себе результат.

Метод

Делаем по кругу

Продукт никогда не «сдан». Каждый цикл — это новая итерация, и сайт сам честно пишет: «Итерация 4 из 15».

Центр

Внимание

Все четыре этапа проходят через центральный диск. Стрелка «итерация» упирается именно в него.

Блок для промта

Вставьте этот текст в промт нового сайта. Полная версия с обоснованиями лежит в EMILIUS-DESIGN-SYSTEM.md.

Сделай сайт агентства «Эмилиус Эдженси» (emilius.agency) как следующую итерацию текущего сайта. Сохрани ДНК:

СМЫСЛ: миссия «Помогать великолепным людям создавать великолепные продукты!». Метод «Делаем по кругу»: годовой цикл из 4 этапов по 13 недель: касдев (01–13) → дизайн (14–26) → разработка (27–39) → маркетинг (40–52) → снова касдев. В центре цикла «внимание». Сайт сам находится в процессе: «Итерация N из 15 до великолепного состояния».

ГЕРОЙ: колесо продукта в inline SVG, самый крупный объект первого экрана. Слои: 52 спектральные риски (op .75), стеклянный диск с белой обводкой, номера 01–52 цветом #009090 (растут против часовой), пунктирный крест спектром (op .5), 4 подписи по дуге с градиентами (op .6), белый центральный диск со спектральным ободом и статичным словом «внимание» (#5A5A5A, 16/600). Неподвижная бирюзовая стрелка «итерация» на 9 часах. Вращение по часовой, 360° за 156 с, linear, бесконечно; при prefers-reduced-motion колесо стоит. При загрузке под стрелкой стоит текущая неделя года.

ВИЗУАЛ: светлая bento-панель на один экран. Фон #F7F7F7 и едва заметные пастельные конические лучи под белой вуалью 65→45%. Карточки #FEFEFE, border 2px #EFEFEF, radius 20, shadow 0 0 10px 2px rgba(210,210,210,.25). Порядок: таблетка логотипа → eyebrow «НАША МИССИЯ» (teal, 700, caps) → H1 38/1.15/600 → три колонки 185/522/185: «Проекты» (круглые логотипы 52px, по hover открывается кейс), «Делаем по кругу» (колесо), «Связь» (кнопки Telegram) и «Спросить 🤖 Эми» (голосовой ИИ).

ЦВЕТ: единственный акцент #00999B (текст на нём #FFFDFD). Текст #000 и #5A5A5A. Спектр #E44854 #C06C60 #E4D830 #B4E43C #30C048 #30D890 #30C0B4 #309CE4 используется ТОЛЬКО в знаке, колесе и фоне. Голосовая кнопка: круг с градиентом #28655E→#617170.

ТИПОГРАФИКА: Glober (фолбэк Manrope). 600 для заголовков и кнопок, 400 для текста. Шкала 38/20/19/17/16/14. Подписи в колесе строчными.

КОМПОНЕНТЫ: Primary: bg #00999B, r13, текст слева, чёрная иконка Telegram справа. Secondary: белая, 1px #00999B, по hover заливается teal за 0.2s. Кейс: скриншот → «Платформа — ниша» → «что сделали, цифры» → domain ↗. Тени без смещения. Анимации только спокойные: fade .2s, color .2s, медленное вращение.

ЛОГОТИП: «Эмилиус [знак] Эдженси» в белой таблетке r20, 1px #ECECEC. Знак: два открытых треугольника (вверх и вниз), соединённые зигзагом-молнией, обводка со спектральным градиентом.

ТОН: русский, тёплый, уверенный, короткий. В кейсах цифры, эмодзи точечно. «Знаем, как надо!»

НЕ ДЕЛАТЬ: тёмную тему по умолчанию, кислотные градиентные кнопки, второй акцентный цвет, длинный лендинг до контактов, резкие или смещённые тени, быстрые пружинящие анимации, капс в заголовках.
