# Концепт v0.1: Emilius как операционная система агентства

Прислано владельцем 22.10.2026 (обсуждение в чате). Статус — **идея, решений по реализации нет**.

## Суть
Не «переделать сайт агентства», а превратить Emilius из лендинга в живую операционную систему агентства, часть которой открыта клиенту.

**Формула:** каждая задача увеличивает капитал опыта Emilius.

Сайт отвечает на три вопроса: что вы умеете? → как вы работаете? → где доказательство? Главное — доказательство.

Сохранить из нынешнего сайта: миссию, идею итераций, «Делаем по кругу», проекты, Эми.

## Модель (из неё выводятся страницы)
1. **Направления** — Front-end, InSales, Tilda, Design, No-code и новые. Верхний уровень системы.
2. **Задачи** — направление, тип, проект, исполнитель, трудозатраты, статус приёмки клиентом. Пример: `Front-end → inSales → кастомизация checkout → 7,5 полезных часов`.
3. **Люди** — профиль с накопленной историей: стек, направления, завершённые задачи, проекты, полезные часы, распределение опыта (например, `inSales 48% / Front-end 31% / No-code 14% / Design 7%`), последние задачи.
4. **Проекты** — кейс как представление реальной работы: задача, что сделано, компетенции, участники, число задач/итераций.
5. **Колесо продукта** — центральный объект, модель процесса: запрос → направление → задача → исполнитель → работа → проверка → результат → следующая итерация.
6. **Продажа** — страницы направлений с автоматическими цифрами: `327 задач / 1 840 полезных часов / 18 проектов / 4 специалиста`.

**Полезные часы** — ключевая метрика, «GitHub contribution graph для агентской работы».

**Public / internal:** внутри — задачи, часы, клиенты, загрузка; на сайте — агрегированные цифры и разрешённые кейсы.

## Главная (набросок)
1. Первый экран: «Создаём и развиваем digital-продукты. Каждая выполненная задача делает нашу команду сильнее.» Мощная типографика, минимум элементов, один интерактивный объект.
2. Колесо продукта.
3. Направления с цифрами (задачи, часы, проекты, специалисты) и «Посмотреть опыт».
4. Живая лента «Сегодня принято клиентом»: проект — направление — часы.
5. Проекты → команда → методология → CTA на задачу.

Позиционирование: от «посмотрите, какие мы креативные» к «вот как устроена наша работа, вот опыт команды — дайте следующую задачу».

Каркас (сетка, типографика, карточки, motion) — по дизайн-системе Anything; содержание — Emilius.

## Открытые вопросы (до начала работ)
- **Какой Anything** взять референсом: anything.com, anything.agency или другой — нужен точный URL для разбора по экранам.
- **Источник данных о задачах и часах.** Часы есть в VnimNomic App, но репозиторий публичный: сырые выгрузки сюда не кладём (`CLAUDE.md`). Нужна схема: где живут данные, что агрегируется для сайта, как обновляется (сборка по расписанию, API).
- **Согласие клиентов** на показ их названий в ленте и кейсах; согласие сотрудников на публичные профили.
- **Что публично**: только суммы по направлениям или и профили людей.
- Соотношение с решениями владельца по главной (миссия, колесо 52 дня, плашка запуска) — что остаётся, что меняется.
