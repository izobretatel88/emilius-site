# Сайт «Эмилиус Эдженси»

**Новая сессия — начни с `docs/HANDOFF.md`:** там состояние проекта, решения владельца, открытые вопросы и известные грабли.

Astro, статическая сборка. Превью: https://izobretatel88.github.io/emilius-site/ (из `main`), черновик экспериментов: https://izobretatel88.github.io/emilius-site/dev/ (из ветки `dev`). Продакшен позже — Бегет.

Основной адрес — `https://emilius.agency` без www (решение владельца от 24.09.2026). `public/.htaccess` уводит www и http на него 301-редиректом.

## Правила

- Цвета, радиусы, тени и шрифты берутся только из `src/styles/tokens.css`. Новые значения сначала появляются там, потом в компонентах.
- Полное описание стиля и границы бренда — в `docs/EMILIUS-DESIGN-SYSTEM.md`. Перед заметными изменениями внешнего вида сверяться с разделами «Что сохранить» и «Чего избегать».
- Колесо продукта — смысловой центр сайта. Годовой цикл: касдев (недели 01–13) → дизайн (14–26) → разработка (27–39) → маркетинг (40–52). Связь «неделя ↔ сектор» не ломать.
- Анимации спокойные: fade 0.2s, смена цвета 0.2s, оборот колеса 156 с. Пружинящие и быстрые эффекты не в стиле бренда.
- Тексты на русском, короткие, с цифрами в кейсах.

## Дизайн в pen.dev

Холсты `.pen` лежат в `design/` и коммитятся вместе с кодом. Выгрузка HTML/Tailwind из pen.dev — только референс раскладки, вёрстка остаётся на компонентах Astro и токенах. Подробности в `design/README.md`.

## Команды

```bash
npm run dev     # localhost:4321
npm run build   # сборка в dist/
npm run brand   # после build: пересобрать favicon, иконки и og.jpg из src/lib/mark.mjs
```

Эксперименты — в ветке `dev` (видны на `/dev/`), после одобрения владельца вливаются в `main`.

Итерации фиксируются в `CHANGELOG.md`, номер итерации — в `src/data/site.ts`, он виден в футере.
