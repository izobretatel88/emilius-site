# emilius-site

Сайт агентства «Эмилиус Эдженси». Статический сайт на Astro: собирается в обычные HTML/CSS/JS, поэтому одинаково хорошо ложится и на GitHub Pages (превью), и на Бегет (продакшен).

## Как работать

```bash
npm install     # один раз
npm run dev     # локально: http://localhost:4321
npm run build   # собрать в dist/
npm run preview # посмотреть собранное
```

## Где лежит дизайн

- `docs/EMILIUS-DESIGN-SYSTEM.md` — дизайн-система: смысл бренда, цвета, шрифты, сетка, компоненты, колесо, тон текстов.
- `docs/wheel-reference.html` — визуальный эталон стиля.
- `src/styles/tokens.css` — те же значения в коде. Менять цвета и радиусы только здесь.
- `docs/assets/` — исходники логотипа, фона и слоёв старого колеса.

## Структура

- `src/data/site.ts` — миссия, ссылки, номер итерации, четыре этапа цикла.
- `src/data/projects.ts` — кейсы. Добавить проект = добавить объект и логотип в `public/projects/`.
- `src/components/Wheel.astro` — колесо: геометрия считается при сборке, в браузере только вращение.

## Превью на GitHub Pages

Пуш в `main` запускает `.github/workflows/deploy.yml`, который собирает сайт и публикует его.
Один раз в настройках репозитория: Settings → Pages → Source → GitHub Actions.

## Публикация на Бегет

```bash
SITE_URL=https://emilius.agency BASE_PATH=/ npm run build
```

Содержимое `dist/` кладётся в корень сайта на хостинге, включая скрытый `.htaccess`: он включает https, убирает www, сжимает файлы и настраивает кеш. Позже выкладку можно автоматизировать через FTP/SSH-деплой в GitHub Actions.

Превью собирается с `PREVIEW=1`: страницы получают `noindex`, а `robots.txt` закрывает всё. Продакшен-сборка без этого флага открыта для поиска и отдаёт `sitemap-index.xml`.

## Итерации

Номер итерации живёт в `src/data/site.ts` и показывается в футере. Каждая заметная порция работы — новая итерация и запись в `CHANGELOG.md`.
