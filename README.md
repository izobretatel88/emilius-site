# extra

Ветка для клиентских и партнёрских материалов Emilius, которые нужно показать по внешней ссылке. Код сайта здесь не живёт: ветка без общей истории с main.

## Содержимое

- `insales-partner-card/` — обновление карточки Emilius.Agency в каталоге партнёров InSales.
  - `stend/index.html` — стенд «Было / Стало / Файлы», на компьютере и на телефоне.
  - `graphics/out/` — готовые PNG: логотип, 4 кейса для портфолио, 4 картинки для описания.
  - `description.md` — текст описания к вставке и порядок обновления карточки.
  - `ITERATIONS.md` — журнал правок.

Страницы стенда закрыты от индексации (`noindex`). `was.html` и `new.html` — копии страницы insales.ru для сравнения, без скриптов InSales.
Шрифт Glober лицензирован и в ветку не входит: шаблон `graphics/cards.html` рендерится только локально, здесь лежат готовые PNG.
