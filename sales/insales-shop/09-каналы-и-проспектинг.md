## 4. Балл проспекта 0–5 (для таблицы лидов)

Совпадает с правилом v2 из прогона 06.10.2026 и уточняет его.

| Признак | Балл |
|---|---|
| Свой бренд / своё производство | +2 |
| Продаёт на 2+ маркетплейсах или 5k+ подписчиков | +1 |
| Повторная категория (косметика, зоо, бельё, детское, еда, бытовое) | +1 |
| Видимая проблема на сайте (нет корзины, ссылки на WB, `tilda.ws`) | +1 |
| Есть публичный контакт (почта/Telegram/VK) | +0 (обязательное условие, без него не берём) |
| Перепродажа без бренда | −2 |
| Поддомен `tilda.ws` **и** нет бренда/производства | −2 (если своё производство и продажи на МП — не снимаем) |
| Бренд не подтверждён | −1 |

Писать только при балле **≥ 3**. 1–2 — в лист ожидания. 0 — не писать.

**Норма ресёрча:** 20 проспектов в день, из них 6–8 с баллом ≥ 3. Перед отправкой — открыть сайт и проверить наблюдение из письма (иначе письмо выглядит как спам и вредит репутации).
