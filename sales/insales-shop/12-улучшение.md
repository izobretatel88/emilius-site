# 12. План улучшения и журнал итераций

## Метрики воронки (считать еженедельно в таблице лидов)

| Этап | Метрика | Цель на 1-й месяц (гипотеза) |
|---|---|---|
| Проспектинг | проспектов с баллом ≥ 3 в неделю | 30 |
| Холодные | ответы / отправленные | ≥ 8 % |
| Квалификация | доля 5+ баллов среди ответивших | ≥ 40 % |
| Этап 0 | оплачено / предложено | ≥ 30 % |
| Смета | договор / смета | ≥ 35 % |
| Производство | факт часов / план | 0,85–1,15 |
| Производство | срок факт / план | ≤ 1,2 |
| После запуска | клиент взял поддержку или следующий заказ в 60 дней | ≥ 50 % |

## Что меняем по данным

| Сигнал | Действие |
|---|---|
| Модуль превышает норматив > 30 % на 2 проектах подряд | Поднять `hours` в `model.mjs`, пересобрать, обновить цены пакетов |
| Модуль стабильно < 70 % | Снизить норматив или включить в базу бесплатно как аргумент |
| Сегмент даёт < 3 % ответов за 50 писем | Переписать повод или выключить сегмент |
| «Дорого» — главная причина отказа в 5+ сделках | Ввести пакет «Витрина» (до 30 товаров, ~65–70 тыс. ₽: модель даёт пол ~30 ч) или рассрочку 50/25/25 |
| «Нет трафика» — главная причина | Продавать связку «Магазин + Директ по бренду» одним пакетом |
| Этап 0 покупают, но магазин нет | Разобрать 5 случаев: цена? источник трафика? |

## Журнал итераций

### v1.0 — 06.10.2026 (автономный прогон)

**Сделано:** база знаний по рынку (01), продукт и лестница (02), каталог из 58 типовых работ в 18 модулях с нормативами (03, генерируется), расчёт пакетов (04), бриф и квалификация (05), процесс из 17 этапов с чек-листами (06), карточка услуги (07), лендинг со структурой и текстами (08), каналы и проспектинг с баллом (09), сообщения по 5 сегментам и реакции (10), продажный диалог и 12 возражений (11), калькулятор (`calculator.html`).

**Проверка и что улучшено внутри итерации:**
1. Первый расчёт «Старта» по модели — 117 тыс. ₽ при рынке 75–115 тыс. ₽. Причины: Этап 0 сидел внутри проекта, завышены нормативы брендирования/страниц/аналитики. Исправлено: Этап 0 вынесен в отдельную цену с зачётом; нормативы снижены до реалистичных для повторяемой работы; добавлен эффект темы Style. Итог: 85 тыс. ₽.
2. Пакет «Бизнес» сначала включал приведение описаний 500 товаров (50 ч контента) → цена 208 тыс. Вынесено в опцию: 140 тыс.
3. Пакет «Витрина» (30 товаров) по модели стоил 78 тыс. — почти как «Старт»: у полноценного магазина есть пол ~30 ч (касса, доставки, юр. страницы, тест, обучение). Пакет убран, вход — через Этап 0. Вернуть, только если «дорого» станет главной причиной отказов.

**Слабые места v1.0:**
- Нормативы — экспертная оценка, не факт Weeek. → бэклог 5.
- Цены конкурентов и тарифы InSales — из поисковых сниппетов. → бэклог 1, 4.
- Нет живых цитат клиентов и интервью. → бэклог 2.
