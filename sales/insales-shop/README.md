# Услуга «Интернет-магазин на шаблоне InSales» — рабочая система продаж и производства

Версия 1.0 · 06.10.2026 · автономный прогон. Владелец услуги — Эмиль, производство — София.

## Коротко

- **Продукт:** рабочий магазин на шаблоне InSales с оплатой, кассой, доставкой, аналитикой и обучением — по фиксированной цене, все доступы на клиенте.
- **Лестница:** Этап 0 «Диагностика» 12 000 ₽ (засчитывается) → «Старт» 85 000 ₽ / ~3 нед. → «Бизнес» 140 000 ₽ / ~4 нед. → «Склад» 210 000 ₽ / 4–5 нед. → поддержка, Директ, SEO.
- **Рынок:** у партнёров InSales — от 15–30 тыс. ₽ (только настройка шаблона) до 75–115 тыс. ₽ «под ключ». Цены почти никто не публикует. Наш ход: открытая цена, состав по строкам, общие остатки с маркетплейсами, Этап 0.
- **Главный сегмент:** бренды и производители на WB/Ozon (A2), потом офлайн с 1С (C) и бренды из соцсетей (B). Перепродавцам без бренда магазин не продаём.
- **Цена считается алгоритмом:** бриф (36 вопросов) → 58 типовых работ с нормативами → часы × ставки регламента → коэффициенты → фикс.

## Как пользоваться

**Продажи.** Нашли проспекта → балл по `09` §4 → письмо из `10` → ответил → 5 вопросов из `05` §1 → бриф → калькулятор → смета → `11` для созвона и возражений.

**Оценка.** Открыть `calculator.html` (двойной клик), выбрать ближайший пакет, поправить ответы брифа, «Скопировать смету для клиента».

**Производство.** `06-процесс.md`: чек-лист материалов в день старта, чек-лист запуска перед сдачей. Факт часов по модулям — в таблицу, отклонения больше 30 % — в `12`.

**Изменить нормативы или цены:**
```bash
# править sales/insales-shop/tools/model.mjs, затем
node sales/insales-shop/tools/build.mjs   # пересоберёт 03, 04 и calculator.html
```

## Решения, принятые в этом прогоне (можно пересмотреть)

1. Ставки — из регламента 27.06.2026 (ноукод 2 400, разработка 3 500, интеграции 3 000, дизайн и SEO 2 400 ₽/ч). Новая роль «контент-менеджер» — 1 500 ₽/ч (**нужно подтверждение**).
2. Этап 0 вынесен в отдельный продукт за 12 000 ₽ с зачётом — вход дешевле, чем у конкурентов, и фильтр незрелых лидов.
3. Пакет «Витрина» (до 30 товаров) не вводим: у полного магазина есть пол ~30 часов, и «Витрина» по модели почти не дешевле «Старта».
4. Тема Style — стандарт для пакетов (экономит время и даёт выручку с темы).
5. Индивидуальный дизайн — не эта услуга.

Открытые вопросы владельцу — `12-улучшение.md`.
