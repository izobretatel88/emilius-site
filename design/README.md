# Дизайн в pen.dev

`.pen` — это JSON, поэтому холсты лежат в репозитории рядом с кодом и версионируются как обычные файлы.

- `home.pen` — первый экран.
- Новые экраны: `<название>.pen` в этой же папке.
- `exports/` — выгрузки HTML/Tailwind из pen.dev. Только справочный материал, в сборку не идут.

## Правило стека

Источник правды по цветам, радиусам и теням — `src/styles/tokens.css`, а не выгрузка из pen.dev.
Экспорт в Tailwind используем как референс раскладки: смотрим размеры и отступы, а верстаем компонентами Astro на токенах.
Иначе в проекте появятся две параллельные дизайн-системы.

## Цикл итерации

1. Правки на холсте в pen.dev, файл сохраняется в `design/`.
2. Claude Code читает холст через MCP и переносит изменения в компоненты.
3. `npm run dev` — смотрим локально.
4. Коммит холста и кода одним коммитом, push.
5. Через минуту правки видны на превью: https://izobretatel88.github.io/emilius-site/
