# Знак-молния

Рабочие файлы второго знака. На сайте не используется — основной знак сайта треугольник с сердцем (`src/lib/mark.mjs`).

- `source-figma.svg` — исходник из Figma (Group 30). Градиент в нём сделан через HTML внутри SVG (`foreignObject`): его показывает только браузер, а Safari в favicon, Pencil, Telegram и графические редакторы покажут пустоту.
- `bolt-master.svg` — тот же знак, переносимый: градиент пересобран из обычных SVG-фигур по матрице Figma, внутренняя тень сохранена. Для размеров от ~64 px.
- `bolt-small.svg` — версия для 16–48 px: линия вдвое толще, просветы между горизонталями шире, без внутренней тени.
- `bolt-line.svg` — **выбранное направление** (24.09.2026): ваша геометрия и пропорции, плавный вертикальный цвет мятный → синий → лаймовый → жёлтый → красный вместо кусков, линия 20. Обычный линейный градиент — отображается везде.
- `bolt-line-small.svg` — то же с линией 24, для иконок 16–24 px.
- `bolt-line-512.png` — знак на прозрачном фоне для аватарок и презентаций.
- `preview.png` — сравнение исходника, мастера и мелкой версии; `preview-line.png` — исходник и три толщины линии в таблетке, крупно, 32 и 16 px, на тёмном фоне.

Пересобрать: `node design/logo-bolt/build.mjs`

## Про мелкие размеры

Знак узкий (2:3), и в квадратной иконке 16 px он занимает около 11 px по ширине. Пропорции сохраняем — сплющенная версия смотрится плохо. Мелкий размер вытягивает более толстая линия (`bolt-line-small.svg`); для аватарок и favicon можно ставить знак на тёмный круг — это даёт контраст на любом фоне.
