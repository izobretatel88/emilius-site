# Знак-молния

Рабочие файлы второго знака. На сайте не используется — основной знак сайта треугольник с сердцем (`src/lib/mark.mjs`).

- `source-figma.svg` — исходник из Figma (Group 30). Градиент в нём сделан через HTML внутри SVG (`foreignObject`): его показывает только браузер, а Safari в favicon, Pencil, Telegram и графические редакторы покажут пустоту.
- `bolt-master.svg` — тот же знак, переносимый: градиент пересобран из обычных SVG-фигур по матрице Figma, внутренняя тень сохранена. Для размеров от ~64 px.
- `bolt-small.svg` — версия для 16–48 px: линия вдвое толще, просветы между горизонталями шире, без внутренней тени.
- `bolt-square.svg` — **выбранное направление** (24.09.2026): та же форма в пропорциях, близких к квадрату, плавный вертикальный переход мятный → синий → лаймовый → жёлтый → красный. Линия 8,5 — по весу как надпись в таблетке. Обычный линейный градиент, отображается везде.
- `bolt-square-small.svg` — то же с линией 10, для иконок 16–24 px.
- `bolt-square-512.png` — квадратный знак 512 px на прозрачном фоне.
- `preview.png` — сравнение исходника, мастера и мелкой версии; `preview-square.png` — квадратный знак в таблетке, крупно, 32 и 16 px, на тёмном фоне.

Пересобрать: `node design/logo-bolt/build.mjs`

## Почему квадрат

Исходный знак узкий (2:3) и в квадратной иконке 16 px занимает около 11 px по ширине. Квадратные пропорции решили это без смены идеи: те же два треугольника с перемычкой.
