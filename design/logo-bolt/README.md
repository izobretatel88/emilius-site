# Знак-молния

Рабочие файлы второго знака. На сайте не используется — основной знак сайта треугольник с сердцем (`src/lib/mark.mjs`).

- `source-figma.svg` — исходник из Figma (Group 30). Градиент в нём сделан через HTML внутри SVG (`foreignObject`): его показывает только браузер, а Safari в favicon, Pencil, Telegram и графические редакторы покажут пустоту.
- `bolt-master.svg` — тот же знак, переносимый: градиент пересобран из обычных SVG-фигур по матрице Figma, внутренняя тень сохранена. Для размеров от ~64 px.
- `bolt-small.svg` — версия для 16–48 px: линия вдвое толще, просветы между горизонталями шире, без внутренней тени.
- `preview.png` — сравнение в размерах 160 / 48 / 32 / 16 и на тёмном фоне.

Пересобрать: `node design/logo-bolt/build.mjs`

## Что ещё можно улучшить в мелкой версии

Знак узкий (пропорции 2:3), поэтому в квадратной иконке 16 px он занимает около 11 px по ширине. Следующий шаг — сделать мелкую версию шире (ближе к квадрату), это решение по форме знака.
